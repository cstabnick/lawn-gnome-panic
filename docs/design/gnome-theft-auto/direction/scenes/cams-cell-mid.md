## 1. Purpose in the story

Cam talks fast, gives up the code and route, and is told by Vesper's voice that there was never a charter. Then he tells the player to do whichever costs less.

## 2. The player's feeling

- **In:** guards cracked, the gap in the wire.
- **Out:** a code in the pocket and a decision to make; some pity.
