A giant, goofy dog in the yard that throws balls for the gnome. It never hurts anyone.

## In the games

- It is in the yard from the start.
- The code marks it as "NEVER kills you!", and it throws a ball when it plays.
- Bonks and airhorns do not stun it.
- The README calls the dog one of the two creatures the gnomes befriend.
