A harmless giant pillbug that wanders, curls up and rolls. The README calls it creepy, and it is friendly.

## In the games

- It is found in the yard and in the Great Deku Oak.
- It wanders until it curls up, then rolls.
- It is not stunned by bonks or airhorns.
- The code calls it a harmless creepy-cute pillbug.
