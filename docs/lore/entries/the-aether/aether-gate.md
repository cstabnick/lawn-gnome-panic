The gate past the last island of a free-ride world, and the finish line of the race down the mountain. Going through it warps the rider back to the first island, so the world loops with no dead ends.

## In the games

- The last run of every world always jumps through the gate.
- Going through it awards the combo line "Aether Warp".
- The world's own description says the gate warps you back to the first island.
- Free ride is a race from the top of the mountain to the gate: the run is timed, and flying off the end of the last run counts as reaching it. The best time is kept per world.
