An acid-funk gang of Woken foundry tools and forged anvil-cymbals holding **Chrome Kiln Foundry** (Area 3 of Gnom Set Radio), led by **Furnace Vera**—a towering living anvil topped with a tilted brass ride cymbal.

## In the games

- Chrome Kiln Foundry forms the third rung of the Broadcast Archipelago's Frequency Ladder (Thermal Wattage / Amplification), boosting DJ Broadcast's signal above the mid-Aether cloud deck.
- Skaters ride exhaust updraft vents between smelter catwalks (4.5m), kiln rim decks (8.5m), and the Crucible Crown (13m) while assisted by local helper gnome **Sooty Slagcap**.
