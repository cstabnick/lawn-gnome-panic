A giant brass trap in the doorway between the fourth and fifth rooms. Walking into it while it is still set hurts the gnome. A heavy acorn springs it flat into a safe bridge.

## In the games

- Until it is sprung, it blocks the doorway, and stepping onto it hurts the gnome. Each time it does, the Gnome-Souls nearby are alerted.
- Springing it counts as clearing an obstacle. The banner reads "SNAP! The Snare-Trap is sprung into a safe bridge."
- Look: a wooden base with a raised brass jaw bar that drops flat when sprung.
