The Gnome Olympics: six quick events for four gnomes, played as minigames inside Gnome Party.

## In the games
- The events are Gnome Sprint, Triple Gnome Jump, Mower Toss, Lawn Dart Javelin, Grass Mowing and Gnome Hero.
- Gnome Sprint is played with two keys, A and D. Gnome Hero is a beat-driven four-lane jam.
- Each event is a party slice. Gnome Party finds them by itself.
