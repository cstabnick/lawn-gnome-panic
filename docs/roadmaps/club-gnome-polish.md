# Club Gnome polish

One epic, run on Haiku workers in parallel (one file each): `glow.ts` (ground glows on portals/spots), `casinoDecor.ts`
(carpet, trim, chandeliers, ropes, neon, cashier) with the gnomecino entry in `maps.ts`, `casinoTables.ts` (dealers, patrons,
cards, chips, waitstaff matching Gnome Blackjack), `hud.ts` (non-blocking bottom, Gnome/account buttons, GitHub + privacy).
Planner: golf cart is the tee-off spot, arcade-shell iframe guard, sign-in via `/me/?signin=1&return=` (Keycloak accepts that
page's URL), site root is Club Gnome and the game list lives at `/games/`, page zoom blocked on mobile.
