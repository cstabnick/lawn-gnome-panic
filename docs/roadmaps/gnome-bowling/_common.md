## World conventions
- Units are metres. y is up; the lane surface is y = 0. The lane runs along +z: foul line at z = 0, head pin at z = `LANE.length` (18.29). x runs across; **+x is the bowler's LEFT**. A yaw `a` points along `(Math.sin(a), 0, Math.cos(a))`; three.js models built facing +z use `object.rotation.y = yaw`, so a bowler facing down the lane has `rotation.y = 0`.
- `src/config.ts` exports (read it for the exact fields): `LANE` (length, halfWidth 0.527, gutterWidth 0.235, gutterDepth 0.09, approach 4.6, deckPastHeadPin 0.95, pitDepth 0.6, lanePitch 1.6, oilEnd 11.5), `BALL` (radius 0.109, mass, releaseZ 0.25), `PIN` (height 0.381, radius 0.061, mass), `PIN_SPOTS` (10 × [x, z], index 0 = pin 1 head pin; 2,4,7 on +x), `ThrowInput {x, aim, speed, spin}`, `THROW` (xRange 0.45, aimRange 0.12, speedMin 3.5, speedMax 10, hookAccel, approachSeconds 1.3), `PinSample {x,z,y,tilt,tiltDir,spin}`, `BallSample {x,y,z,roll}`, `SimEvent {t, kind:'release'|'gutter'|'ballPin'|'pinPin'|'pinFall'|'pit', strength 0..1, pin}`, `SimResult {sampleDt, ball[], pins[p][i], duration, down[10], gutter, reachPinsAt, events[]}`, `LOOKS` (LookId → {name, look: GnomeLook}), `LOOK_ORDER`, `SEAT_COLORS`, `MAX_LOCAL_PLAYERS` 4, `MAX_ONLINE_PLAYERS` 4, `Player {name, look, color, rolls, local, netId, gone}`, `Phase`, `ResultKind`, `BallResult {kind, count, player, serial}`, `NetStatus`, `GameState`, `ROUND`, `NetApi`, `Ctx`, `System`, `LOOK_COLORS`.
- `ctx` (`Ctx`): `scene`, `camera` (PerspectiveCamera), `renderer`, `canvas`, `state` (GameState), `ui`, `lights.key` (DirectionalLight with shadows), `lights.hemi`, `net` (NetApi).
- `state` (GameState): `phase`, `phaseTime` (s in phase), `time`, `mode` ('local'|'online'), `players`, `current` (index of the bowler), `frame` (0..9), `ballInFrame` (0..2), `standing` (10 booleans: pins on the deck now), `aimX`, `aimYaw` (current aim), `input` (ThrowInput in flight or null), `sim` (SimResult or null), `rollTime` (s since release during 'roll'), `result` (BallResult or null), `turn`, `net` (NetStatus).
- Phase flow (game.ts `tickGame` runs before every system each frame): title → (newGame) intro (ROUND.introSeconds) → aim → (throwBall) approach (THROW.approachSeconds; the ball is still in the hand) → roll (sim plays; ball at `sim.ball[floor(rollTime / sim.sampleDt)]`, clamp the index to the last sample) → result (ROUND.resultSeconds, or bigResultSeconds for strike/double/turkey/hambone) → aim again (same bowler's next ball; `state.standing` already updated, knocked pins are gone) or intro (next bowler, full rack) … → final. Online: title → lobby → intro …
- During 'result', `state.standing` already has the knocked pins set false, while `state.sim` still holds the throw (so views can leave the knocked pins lying where they fell until the phase ends).
- game.ts exports: `newState()`, `makePlayer(name, look, color, local = true, netId = -1)`, `newGame(state, players, mode)`, `toTitle(state)`, `toLobby(state)`, `currentPlayer(state)`, `canBowlHere(state)` (phase 'aim' and the bowler is local), `setAim(state, x, yaw)` (clamped), `throwBall(state, input)`, `queueRemoteThrow(state, netId, turn, input, downMask)`, `removePlayer(state, netId)`, `strikeStreak(player)`, `pinsToMask(down)`, `maskToPins(mask)`, `hooks.onLocalThrow`.
- scoring.ts exports (pure): `framesOf(rolls)`, `cursor(rolls)` → `{frame, ball, done, fresh}`, `frameScores(rolls)` → 10 running totals or null, `totalScore(rolls)`, `maxPossible(rolls)`, `frameMarks(rolls)` → 10 arrays of 'X' | '/' | '-' | digit, `isSplit(standing)`.
- Gnome models: `import { createGnomeModel } from './models/gnome'` → `GnomeModel {object, arms: {left, right} (shoulder pivots: rotation.x swings an arm forward/back, 0 = hanging down, negative = forward/up), rig (body group; rotation.y twists the body), update(p, dt), setDead(b)}`. `update` reads a PlayerState `{ position: THREE.Vector3 (feet), velocity: THREE.Vector3, facing, grounded: true, jumpsUsed: 0, stamina: 1, staminaDelay: 0, sprinting: false, exhausted: false }` and walks from the velocity (zero = standing). Call it every frame, then pose arms after it (it overwrites arm rotation.x while walking). A gnome is ~1.1 m tall, built facing +z, its left is +x, the right hand (arms.right) is at -x. Every look in `LOOKS` has a bowl cut. Use `{ ...LOOKS[id].look, hat: player.color }` so the hat shows the player's colour.
- Sounds: `import { sfx, startAudio } from './audio'`: `sfx('click'|'tick'|'swoosh'|'thud', volume?)`, `startAudio()` (call it inside your first pointerdown/keydown handler).
