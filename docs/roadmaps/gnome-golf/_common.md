## World conventions (read src/config.ts and src/round.ts for the exact types)
- Units are yards. y is up; the sea and ponds are the plane y = 0 (anything where ground height < 0 is water). The island is centred on the origin, roughly x in [-640, 640], z in [-510, 510].
- Directions: a yaw `a` points along `(Math.sin(a), 0, Math.cos(a))`; the right-hand side of that is `(-Math.cos(a), 0, Math.sin(a))`. three.js models built facing +z use `object.rotation.y = yaw`.
- `src/course.ts` (pure functions): `heightAt(x, z)` ground height, `lieAt(x, z)` -> `'tee'|'fairway'|'fringe'|'rough'|'sand'|'green'|'water'`, `gradientAt(x, z)`, `distToPath(hole, x, z)` -> `{dist, along}`, `holeLength(hole)`, `distToCoast(x, z)` (> 0 on land), `coastRadius(theta)`.
- `src/config.ts`: `HOLES` (9 holes: `par`, `tee`, `path` (tee, corners, green centre), `fairwayWidth`, `green {x,z,r,slopeX,slopeZ}`, `pin {x,z}`, `bunkers`, `ponds`), `CLUBS`/`CLUB_ORDER` (club ids `'DR'|'3W'|'4H'|'5I'|'6I'|'7I'|'8I'|'9I'|'PW'|'GW'|'SW'|'PT'`), `LIES`, `PHYS`, `SWING`, `ROUND`, `PARTY`, `LOOK` (colours), `GOLFER_LOOK`, `PARTNER_LOOK`, `CLUBHOUSE`, `ISLAND`.
- `ctx` (`Ctx`): `scene`, `camera` (PerspectiveCamera), `renderer`, `canvas`, `state` (GameState), `ui`, `lights.sun` (DirectionalLight, castShadow, its `target` is in the scene), `lights.hemi`.
- `state` (GameState): `phase` (`'title'|'intro'|'aim'|'swing'|'flight'|'result'|'drive'|'holed'|'card'|'final'`), `phaseTime` (seconds in this phase), `time` (seconds since load), `holeIndex` (0-based), `strokes`, `scores` (per hole, null = not played), `ball` (THREE.Vector3, ground position of the ball at rest), `lie`, `aimYaw`, `club`, `wind {yaw, mph}` (yaw = direction it blows toward), `swing {stage:'idle'|'power'|'accuracy', marker, power}`, `flight` (ShotResult | null: `points` THREE.Vector3[] sampled every `sampleDt` s from impact, `duration`, `events` [{t, kind:'bounce'|'roll'|'cup'|'water'|'rest', lie, speed}], `end`, `endLie`, `holed`, `carry`, `apex`, `total`), `lastShot`, `banner`, `party {golfer, mower, partner}` (each a Spot `{x, y, z, facing}`), `drive` ({from, to, duration} | null), `view` (`'behind'|'overhead'`).
- Phase flow (round.ts drives it; `tickRound` runs before all systems each frame): title -> (newRound) intro -> aim -> swing -> flight -> result -> drive -> aim ... -> holed -> card -> (nextHole) intro ... -> final. In 'flight' the ball is at the trajectory sample for `state.phaseTime`; `state.ball` is still the start position until 'result'.
- round.ts functions: `newRound(state)`, `startHole(state, i)`, `skipIntro(state)`, `takeShot(state, shot)`, `nextHole(state)`, `setAim(state, yaw)`, `cycleClub(state, delta)` (-1 = longer club, +1 = shorter), `currentHole(state)`, `distanceToPin(state)`, `yawTo(x, z, tx, tz)`, `scoreName(strokes, par)`, `roundTotals(state)`, `fmtDistance(yards, lie)` (feet near the green, else yards), `mowerPose(state)` (the mower's current Spot + speed, moving during 'drive').
- physics.ts functions: `estimateCarry(club, lie = 'fairway', power = 1)` (yards: carry for full swings, roll distance for the putter), `previewLanding(start, club, lie, yaw, pin)` (THREE.Vector3 where a perfect full-power shot first lands, no wind; for the putter where the full putt stops; costs ~5 ms, so cache it), `launchSpeed(club)`.
- Gnome models: `import { createGnomeModel } from './models/gnome'` -> `GnomeModel {object: THREE.Group, arms: {left, right} (shoulder pivots), rig, update(p, dt), setDead(b)}`. `update` reads a PlayerState: `{ position: THREE.Vector3 (feet), velocity: THREE.Vector3, facing: number, grounded: true, jumpsUsed: 0, stamina: 1, staminaDelay: 0, sprinting: false, exhausted: false }`; it copies position/facing onto `object` and animates walking from the velocity (zero velocity = standing still). A gnome is about 1.1 yards tall, built facing +z, its left is +x. Looks: `GOLFER_LOOK`, `PARTNER_LOOK` from config.ts, or build a `GnomeLook` (`{hat, shirt, pants, skin, boots, beard: number|null, hair: {color, style:'pigtails'}|null, freckles, dress, glasses}`).
- Sounds: `import { sfx, startAudio } from './audio'`; `sfx(name, volume?)` with names `'swing'|'hit'|'putt'|'bounce'|'sand'|'splash'|'cup'|'tick'|'click'|'cheer'`.
- Consumables (added in epic 3; config.ts `CONSUMABLES`, state fields): `state.cigarillos` (left this round, starts 3), `state.smokeShots` (> 0 = a cigarillo is lit and in the golfer's mouth; counts down by 1 at every shot, so a cigarillo lasts 3 shots), `state.beers` ("golf water" cans left, starts 6), `state.beersDrunk`, `state.drinkTime` (seconds into the current sip, -1 when not drinking; a sip lasts `CONSUMABLES.drinkSeconds` = 2.4 s, tickRound advances and ends it). round.ts: `lightCigarillo(state)` and `drinkGolfWater(state)` (both only in phase 'aim', return true if it happened), `meterSpeedScale(state)` (0.6 while smoking, else 1). Golf water is beer and has no effect on play; it is just funny.
- More sfx names (epic 3): `'light'` (lighter flick + puff), `'crack'` (can opened), `'sip'` (gulp).
