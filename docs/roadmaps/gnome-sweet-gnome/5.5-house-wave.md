## Goal
On the house screen, built items look lifted off the scene (soft 3D drop shadows) and gently wave: each item sways around its base and breathes a little, out of phase with its neighbours, like a cosy living diorama. Building an item gets a bouncy 3D "drop in" from above.

## Change
- `games/gnome-sweet-gnome/src/scenes/HouseScene.ts`:
  - **Pivot at the base**: position each built slot's Graphics at `(slot.x, slot.y + slot.h / 2)` and draw the item at local `(0, -slot.h / 2)`, so rotation and scale happen around the item's base. Update every place that uses the slot Graphics position (build pop, bursts) accordingly. Unbuilt junk and outlines can stay as they are.
  - **Wave**: one `this.events.on('update', ...)` handler (removed on shutdown and on rebuild) that, for each built slot Graphics, sets `angle = A * sin(t * 1.3 + phase)` and `scaleY = 1 + 0.015 * sin(t * 2 + phase)`, `scaleX = 1 - 0.008 * sin(t * 2 + phase)` (squash and stretch), where t is seconds, `phase = slot.x * 0.011 + slot.y * 0.007`, and `A` = 1.6 degrees for most items, 3 for plants, trees, flowers, lanterns, lamps and curtains (art keys: tree, flowerbed, lanterns, lamp, curtains), and 0.6 for big structural ones (roof, fence, path, rug, fireplace, cupboard, stove, windows, door, chimney). Respect `prefers-reduced-motion` (quarter amplitude). Do not fight the build pop tween: skip a slot's wave while it is tweening (keep a Set of slot ids being tweened).
  - **3D shadow**: when WebGL, `g.enableFilters()` and `g.filters.internal.addShadow(...)` on each built slot Graphics for a soft drop shadow to the lower right (try x 0.6, y 0.8 offsets, low decay; check what the parameters do in phaser.d.ts and tune until it looks like a soft shadow, not a hard copy). If the filter API misbehaves, fall back to drawing the item a second time in black at alpha 0.22, offset (+8, +10) design px, behind the item.
  - **Build drop-in**: replace the scale pop with: the item starts 120 design px higher, alpha 0, scaleY 1.3; tweens down with `Bounce.easeOut` (450 ms) to its spot, then a squash (scaleY 0.85, scaleX 1.1, 90 ms yoyo); then the existing bursts and sound. Restyle uses a quick spin-and-pop (angle 0 -> 360 over 350 ms, `Cubic.easeOut`).
  - The area backdrop gets a gentle 3D feel too: a slow parallax drift of the whole area container (x +-3 design px, y +-2, over ~6 s, sine, yoyo, repeat forever).
