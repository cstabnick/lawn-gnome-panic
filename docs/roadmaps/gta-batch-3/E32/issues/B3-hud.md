## Goal
The golf HUD's scorecard fits nine holes on a phone, and the hole strip no longer covers the birding pill on a phone in
portrait.

## Change
- `src/golf/hud.ts`:
  1. **Phone portrait strip** (`placeTop`, narrow = innerWidth < 600 and not landscape): keep `top: safe-top + 250px`
     but anchor the strip to the right: `left: auto; right: calc(env(safe-area-inset-right) + 8px); transform: none;
     max-width: calc(100vw - 160px)` so it clears the birding row at the left. On wide screens restore exactly the old
     values (`left:50%; right:auto; transform:translateX(-50%); max-width:92vw`). Card/Quit buttons and the banner keep
     their current positions.
  2. **Scorecard with nine rows**: `CardView.holes` now has 9 entries in card order. Make the table compact: font 13 px,
     cell padding 3px 5px, the hole-name column `max-width: 34vw; overflow: hidden; text-overflow: ellipsis;
     white-space: nowrap`, and the card box `max-height: 92%; overflow-y: auto` (keep). After hole 9's row add a
     **Total** row: par = sum of pars, strokes = sum of the non-null strokes (or '–' when none), best = '–'.
     Show strokes relative to par with the existing colouring if there is one; otherwise plain numbers.
  3. Header text: if the card's title says anything about four holes, change it to `Hedgeworth Links · Nine holes`.
- `src/golf/hud.test.ts`: tests for the 9 rows + Total row (a CardView with 9 holes), and that `placeTop` with a
  narrow portrait window sets the strip's `right` (not `left: 50%`). Look at how the existing tests fake `innerWidth`.
