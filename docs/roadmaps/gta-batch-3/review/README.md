# R1: editorial review of Gnome Theft Auto batch 3

The last phase before the batch PR merges (user item L117): editors review everything by content group, a decider
settles questions of spirit, and fix rounds run until a round finds no blockers and only nits. Process:
[docs/process/big-batch-orchestration.md](../../../process/big-batch-orchestration.md), "Editorial review".

## Files

- `G<n>-<name>.md`: one editor's findings per round (numbered; what, where, why, proposed fix, severity
  blocker/polish/nit, *craft* or *spirit*).
- `decisions.md`: the decider's rulings on spirit questions and editor disagreements (options, pros/cons, lore, the
  decision and a one-line reason).
- `rounds.md`: per round, the counts per group and which fix epics ran.
