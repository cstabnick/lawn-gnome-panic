## Goal
Walk-in interiors look deliberate from the dollhouse follow camera: (a) wall decor (signs, paintings, shelves hung on
a wall) hides together with its wall when the camera is outside that wall; (b) signs read as mounted (a darker backing
board); (c) no sky or void shows above the cut-away ceiling: while inside, the scene background and fog are a dark warm
neutral, and the ceiling plane overhangs the walls; (d) the runtime tells the camera the room's ceiling height.

## Change

### interiors/kit.ts
1. Tag the room shell: every mesh made by `room()` (floor, the 4 walls, skirting, ceiling), `door()` (posts, lintel,
   panel) and `window()` (bars, pane) gets `mesh.userData.shell = true`.
2. Tag residents: in `npc()`, set `model.object.userData.interiorNpc = true`.
3. Ceiling overhang: in `room()`, make the ceiling plane `w + 2 * CEILING_LIP` by `d + 2 * CEILING_LIP` with
   `const CEILING_LIP = 6;` (still at y = h, still facing down, same material). It closes the gap between the cut-away
   wall and the camera so the top of the frame shows ceiling, not sky.
4. Sign backing: in `sign()`, add a second plane behind the text plane: size `(w + 0.08) x (h + 0.08)`, colour = the
   sign's `bg` multiplied by 0.55 (use `new THREE.Color(bg).multiplyScalar(0.55)`), `MeshBasicMaterial`, put on draw
   layer (see below), positioned 0.01 m behind the text plane (towards the wall: the text plane's
   front faces direction (sin yaw, cos yaw), so the backing sits at `x - sin(yaw) * 0.01, z - cos(yaw) * 0.01`) with
   the same `rotation.y = yaw`. Draw layers (higher wins): put the backing on `LAYER.marking` (5) and keep the TEXT
   plane on `LAYER.decal` (6), so the text always draws over its backing. Group the two planes in a `THREE.Group` (name `'sign'`,
   added with `add()`), so the pair hides together.
5. Wall decor: `createKit` returns a third field `walls: () => WallDecor[]` beside `kit` and `build`:
   ```ts
   export interface WallDecor {
     /** A point on the wall plane and the wall's inward normal (local coordinates, y ignored). */
     x: number; z: number; nx: number; nz: number;
     /** Direct children of the kit group that hang on this wall. */
     objects: THREE.Object3D[];
   }
   ```
   Empty array when `room()` was never called. The four walls are the ones room() builds: north (0, -hd) normal (0, +1);
   south (0, hd) normal (0, -1); west (-hw, 0) normal (+1, 0); east (hw, 0) normal (-1, 0) (store hw, hd from room()).
   Classify every direct child `c` of `group` at the moment `walls()` is called (the runtime calls it after
   `def.build(kit)`), skipping children with `userData.shell` or `userData.interiorNpc`:
   - compute its bounds: `c.updateMatrixWorld(true); const bb = new THREE.Box3().setFromObject(c);` (skip empty boxes);
   - signs (the groups from step 4: mark them `userData.wallSign = true`) belong to the wall whose plane is nearest
     their centre, if that distance is < 0.4 m;
   - any other child belongs to a wall when ALL hold: `bb.min.y >= 0.25` (it hangs, it does not stand on the floor),
     its thickness across that wall is <= 0.6 m (for the north/south walls `bb.max.z - bb.min.z`, for west/east
     `bb.max.x - bb.min.x`), and its far side is within 0.45 m of the wall plane (north: `bb.min.z <= -hd + 0.45`;
     south: `bb.max.z >= hd - 0.45`; west: `bb.min.x <= -hw + 0.45`; east: `bb.max.x >= hw - 0.45`). If two walls
     match (a corner), take the nearer one.
   Export `WallDecor` from kit.ts.

### interiors/runtime.ts
1. In `doEnter`: `const { kit, build, walls } = createKit(p);` and after `def.build(kit)` keep `wallDecor = walls()`
   (module-local `let wallDecor: WallDecor[] = []`, cleared in `doLeave` and `refresh`). Also call
   `setInteriorCeiling(roomHeight)` where the room height is `def.size.h` (import from './ceiling'); in `doLeave` call
   `setInteriorCeiling(null)`.
2. In `update(dt)`, while inside (after the existing `if (current === null || phase === 'out') return;`):
   - Wall decor: if `deps.camera` and `group`, take the camera position in room-local coordinates
     (`cx = camera.position.x - group.position.x`, `cz = camera.position.z - group.position.z`; the group is never
     rotated or scaled). For each wall: `const outside = (cx - w.x) * w.nx + (cz - w.z) * w.nz < 0;` and set
     `o.visible = !outside` for each of its objects.
   - Background and fog: a dark warm neutral from the theme's ceiling colour:
     `indoorBg.setHex(p.theme.ceiling).multiplyScalar(0.35).lerp(WARM_DARK, 0.5)` with
     `const WARM_DARK = new THREE.Color(0x1c1610)` (both module-level/closure colours, no allocation per frame). Then
     `if (deps.scene.background instanceof THREE.Color) deps.scene.background.copy(indoorBg); else deps.scene.background = indoorBg.clone();`
     and `if (deps.scene.fog instanceof THREE.Fog) { deps.scene.fog.color.copy(indoorBg); deps.scene.fog.near = 80; deps.scene.fog.far = 600; }`.
     Do not touch anything on leaving: atmosphere.update re-writes background and fog the next frame.
