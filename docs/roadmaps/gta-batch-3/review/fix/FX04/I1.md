## Goal
Today every vehicle collides as one circle of `spec.radius` (about half its LENGTH), so a van stops ~1 m short of a wall it
drives along and a dirt bike cannot pass two bollards 1.6 m apart. After this issue every ground vehicle that has
`spec.halfWidth` collides as a short capsule along its heading, against boxes (walls, props) and against other vehicles.
`spec.radius` stays for culling, the camera, spawn spacing, `clampToWorld`, the bump spin lever and damage thresholds.

## Change
- `collide.ts`: add, exported:
  ```ts
  /** Padding beyond the body's half-width (D36). */
  export const CAPSULE_PAD = 0.05;
  /** A vehicle's collision capsule: circles of radius r at the centre +- off along the heading (off 0 = one circle). */
  export interface Capsule { r: number; off: number }
  /** r = halfWidth + CAPSULE_PAD, off = max(0, radius - r) (the ends reach spec.radius along the heading, as before).
   *  No halfWidth: { r: radius, off: 0 } (the old circle). */
  export function vehicleCapsule(spec: { radius: number; halfWidth?: number }): Capsule;
  /** Like sweepCircleBoxes, for a capsule whose heading is yaw (forward = (sin yaw, cos yaw)). With off 0 it must return
   *  exactly what sweepCircleBoxes(x0, z0, x1, z1, c.r, boxes, y) returns. */
  export function sweepCapsuleBoxes(x0: number, z0: number, x1: number, z1: number, yaw: number, c: Capsule, boxes: readonly Box[], y = 0): Pushed;
  /** Closest distance between two capsules' centre segments, and the unit normal from a to b at the closest points
   *  (falls back to the centre-to-centre direction, then (1, 0), when the segments touch). */
  export function capsuleGap(ax: number, az: number, ayaw: number, a: Capsule, bx: number, bz: number, byaw: number, b: Capsule): { dist: number; nx: number; nz: number };
  ```
  Implementation of `sweepCapsuleBoxes`: same substep scheme as `sweepCircleBoxes` (step length <= 0.4 * c.r, at most 32
  steps). The capsule is 3 circles (centre, +off, -off) when off > 0.5 * r, else 2 circles (+off, -off), else 1. After
  each substep, for each circle call `pushOutOfBoxes(circleX, circleZ, c.r, boxes, y)` and shift the whole capsule centre by
  that circle's correction; do the circle pass twice (seams, inside corners), keep the last hit normal, and remove the
  into-wall part of the remaining displacement exactly as `sweepCircleBoxes` does. Return the capsule centre.
- `vehicles.ts`: `moveVehicle` and `stepKnock` call `sweepCapsuleBoxes(x0, z0, v.x, v.z, v.yaw, vehicleCapsule(v.spec), world.boxes, v.y)`
  instead of `sweepCircleBoxes`. Keep `clampToWorld(..., v.spec.radius)`.
  `collideVehicles`: the contact test and the push-apart use the capsules: `capsuleGap` at the end of the frame gives
  `dist`, normal (from a to b); `overlap = ca.r + cb.r - dist`. Keep the existing tunnelling guard (centres that crossed
  this frame, from the relative velocity segment p0 -> p1): when the centres' closest approach this frame was under
  `ca.r + cb.r` while the end-of-frame gap is clear, still treat it as a contact with the p0 normal as today. Keep the
  mass shares, the impulse, `spinOf` (it uses `spec.radius` as its lever: leave it), the damage rule and the debounce.
  Do not touch anything else in `vehicles.ts` (another change already wired `bodyRoll` into `syncVehicleMesh`; leave it).
- `simdrive.ts` `stepChassis`: the building sweep uses `sweepCapsuleBoxes(x0, z0, body.pos.x, body.pos.z, v.yaw, vehicleCapsule(v.spec), world.boxes, <same y as now>)`. Leave everything else.
