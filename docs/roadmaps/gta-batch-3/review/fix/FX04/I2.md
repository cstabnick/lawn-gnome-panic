## Goal
`VIEW.drive` in `camera.ts` is a fixed 8.5 m back and 1.8 m look height for every vehicle, so the Combine (5.3 m tall) and
the Boot Float (7.1 m tall) fill the screen from behind and hide the road, and small rides sit tiny in the distance. After
this issue the drive and fly views scale their distance, look height and default pitch from the driven vehicle's size,
eased when the size changes (switching vehicles), and a normal ride-on (radius 1.4, height ~1.7) looks the same as today.

## Change
- `camera.ts`:
  - Export a measuring helper, cached per object (WeakMap), measured once on the first call:
    ```ts
    /** The driven vehicle's size for the chase camera: bounding radius (spec.radius) and body height (top of its meshes above its origin, m). */
    export function vehicleFrame(obj: THREE.Object3D, radius: number): { radius: number; height: number };
    ```
    Height: `obj.updateMatrixWorld(true)`, union of every visible `THREE.Mesh`'s geometry bounding box in world space, minus
    `obj.position.y`... but skip meshes whose material is `transparent` or has `depthWrite === false` (headlight beams and
    glows), and clamp the result to [0.3, 12]. Use the world bounds' max.y minus obj's world position y.
  - Export the pure sizing so it can be tested:
    ```ts
    export const SIZE_VIEW = { distBase: 6.2, distPerRadius: 1.6, lookFrac: 0.9, lookMin: 1.8, tallFrom: 3, pitchPerMetre: 0.04, pitchMax: 0.34, flyDistBase: 13, ease: 3 };
    /** Drive/fly view numbers for a vehicle of this size: dist, lookHeight, pitch. */
    export function sizedView(mode: 'drive' | 'fly', size: { radius: number; height: number }): { dist: number; lookHeight: number; pitch: number };
    ```
    drive: `dist = distBase + distPerRadius * radius`; `lookHeight = max(lookMin, lookFrac * height)`; `pitch = VIEW.drive.pitch + clamp((height - tallFrom) * pitchPerMetre, 0, pitchMax - VIEW.drive.pitch)`.
    fly: `dist = max(VIEW.fly.dist, flyDistBase + distPerRadius * radius)`, `lookHeight = max(VIEW.fly.lookHeight, 0.5 * height)`, `pitch = VIEW.fly.pitch`.
    (Ride-on: radius 1.4 -> dist 8.44, look 1.8, pitch 0.2: today's view. Combine: 11.3 / 4.7 / 0.29. Boot Float 3.8 / 7.1: 12.3 / 6.4 / 0.34.)
  - In `update`: when `mode` is `drive` or `fly` and `extra?.size` is given, compute `sizedView(mode, extra.size)` and ease
    three private numbers (`curDist`, `curLook`, `curPitch`) toward it with `1 - Math.exp(-SIZE_VIEW.ease * dt)`; snap on the
    first use (when they are unset). Use them in place of `v.dist`, `v.lookHeight` and `v.pitch` (the pitch-return target)
    for that frame. Every other mode, or no size: exactly today's numbers (and reset the eased numbers so the next drive
    snaps). First person and the showroom are untouched.
- `app.ts`: only that one `chase.update(...)` call: add `size: v ? vehicleFrame(v.object, v.spec.radius) : undefined` to
  the extra object, and add `vehicleFrame` to the existing `./camera` import. Nothing else in app.ts.
- New `camera.size.test.ts` (vitest): `sizedView('drive', {radius: 1.4, height: 1.7})` is within 0.1 m of today's 8.5 /
  1.8 and pitch 0.2; the Combine and Boot Float get a larger dist and lookHeight and a higher pitch, capped at 0.34; a
  skateboard (radius 0.45, height 0.6) gets lookHeight 1.8 and dist >= 6.5; `vehicleFrame` on a group holding a 2 m tall
  box mesh at y 1 returns height ~2 and ignores a transparent mesh placed 10 m up; a second call returns the cached value.
