## Change
- New `games/gnome-theft-auto/src/stageSets.ts`:
  ```ts
  import * as THREE from 'three';
  import { buildStaticPrefabs, type StaticPrefabPlacement } from '@lawn/prefabs';
  import { STAGES, stageSetBoxes } from './quests/stages';
  import { heightAt } from './terrain';
  import type { Box } from './types';

  /** Builds every stage's `set` props (one static batch) and pushes their solid colliders into `boxes`. */
  export function buildStageSets(scene: THREE.Scene, boxes: Box[]): { group: THREE.Group; count: number };
  /** Debug overlay for ?stagemarks: marks, cameras, vehicle marks, walks and paths of every stage. */
  export function buildStageMarks(scene: THREE.Scene): THREE.Group;
  ```
  - `buildStageSets`: placements = for every stage, for every `SetProp p`:
    `{ id: p.prefab, x: p.at[0], y: heightAt(p.at[0], p.at[1]), z: p.at[1], yaw: p.yaw, scale: p.scale ?? 1 }`. Build
    with `buildStaticPrefabs(placements, { lights: false, name: 'stage-sets' })`, `scene.add` it, then
    `boxes.push(...stageSetBoxes())`. Return the group and `placements.length`. With no props, return an empty group
    and count 0 (and add nothing).
  - `buildStageMarks`: a `THREE.Group` named 'stage-marks' with, per stage (y = `heightAt` at each point):
    actor marks = a 0.25-radius, 1.6-tall yellow cone (`0xffd23f`) with a short arrow (a thin box 0.6 long) pointing
    along the mark's yaw, lifted by `mark.lift ?? 0`; cameras = a 0.4 blue box (`0x4aa3ff`) at `from` plus a
    `THREE.Line` from `from` to `look`; vehicle marks = a red (`0xd8342c`, parked), orange (`0xf08a24`, pull-up) or
    white (`0xffffff`, exit) box 1.2 x 0.5 x 2.2 turned to the yaw; walks = green (`0x3fa34d`) lines 0.15 m above the
    ground; paths = magenta (`0xff3fb0`) lines 0.15 m above the ground (sample long segments every 4 m so the line
    follows the terrain). Use `THREE.MeshBasicMaterial` / `THREE.LineBasicMaterial`, one shared material per colour.
- `games/gnome-theft-auto/src/app.ts`: import `{ buildStageMarks, buildStageSets }` from `./stageSets` and, directly
  after `hud.setWorld(world);`, add:

  ```ts
  // Stage set dressing for story and side-quest scenes (src/quests/stages.ts); ?stagesets=0 leaves it out, ?stagemarks shows the stage marks.
  const pageParams = new URLSearchParams(location.search);
  if (pageParams.get('stagesets') !== '0') buildStageSets(scene, world.boxes);
  if (pageParams.has('stagemarks')) scene.add(buildStageMarks(scene));
  ```
  (If the name `pageParams` is already taken in app.ts, pick another.) Change nothing else in app.ts.
