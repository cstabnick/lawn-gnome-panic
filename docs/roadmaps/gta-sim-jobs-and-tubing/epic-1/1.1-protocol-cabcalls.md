## Change
- `src/jobs/protocol.ts`: implement the 7 functions. Exact rules:
  - `encodeCab(c)`: `rec = [c.id, qPos(c.x), qPos(c.z), c.takenBy ?? -1, c.state]`; `str = dest + '|' + name` where name
    has every `|` removed and is cut to `JOB_WIRE.maxName` characters.
  - `decodeCab(rec, str)`: null unless `rec.length === 5`, every value an integer, `1 <= id <= maxId`, `takenBy >= -1`,
    state in {0,1,2}. `str` undefined -> dest '' and name ''. Else split at the FIRST `|`: dest must match
    `JOB_WIRE.destRe` (else null), name is the rest (1..maxName chars, else null). takenBy -1 -> null. x/z via uqPos.
  - `decodeDropArgs(a)`: null unless `a.length === 2` and both integers; fare clamped to 0..maxFare, stars to 1..5.
  - `encodePax(p)`: `[1, clamp(parcels, 0, maxParcels), seat, seed, seat, seed, ...]`, at most `maxPaxSeats` pairs
    (drop extras), seat clamped 1..maxSeat, seed clamped 0..maxSeed, all rounded to integers.
  - `decodePax(rec)`: null unless rec[0] === 1, length >= 2 and even (2 + 2*pairs), pairs <= maxPaxSeats, all integers,
    parcels in bounds, each seat 1..maxSeat, each seed 0..maxSeed.
  - `encodeTow(t)`: `[1, on ? 1 : 0, clamp(round(score), 0, maxPoints), clamp(round(gates), 0, maxGates)]` then for slot
    0..2: `who, qPos(x), qPos(z), qAngle(yaw)`; a missing slot is `TOW_EMPTY, 0, 0, 0`. Length always 16.
  - `decodeTow(rec)`: null unless length 16, rec[0] === 1, all integers, on in {0,1}, score/gates in bounds, each who
    >= -2. Returns slots with uqPos / uqAngle.
- `src/jobs/cabCalls.ts`: implement every stub exactly as its doc comment says. Notes:
  - `riderCall` returns false unless `r.phase === 'idle'`; on success phase 'calling', `id = r.id + 1` (wraps to 1 past
    0x7fffffff), name/x/z/dest/at set, driver null.
  - `riderWire` returns `{ id, x, z, takenBy: driver, state: stateOf(phase), dest, name }`, or null when idle.
  - `driverSee` stores `{ owner, call, seenAt: now }` under `callKey(owner, call.id)`. `driverForget` deletes it.
  - `openCalls` returns SeenCalls whose `call.state === 0 && call.takenBy === null`, sorted by distance from (x, z).
  - `driverTake` fails (null) when `d.job !== null`, the key is unknown, or the call is not open.
  - `driverStatus`: job null -> null; key missing from `calls` -> job = null, 'gone'; `takenBy === myId` -> 'ok';
    `takenBy !== null` (someone else) -> job = null, 'lost'; else 'pending'.
- New `src/jobs/protocol.test.ts`: round-trips for cab, pax, tow (positions equal within 0.05 m, yaw within 0.03 rad);
  every malformed case named above returns null (at least 12 cases); name with `|` and 40 characters encodes to a
  valid 24-char name.
- New `src/jobs/cabCalls.test.ts`: a full happy path (rider calls -> driver sees open call -> driverTake -> rider gets
  take from that driver -> 'assigned' -> riderWire shows takenBy -> driverSee of that record -> driverStatus 'ok' ->
  riderTick with seatedWith = driver -> 'riding' -> rider gets drop -> 'paid', phase idle); two drivers take the same
  call: the second take is ignored by the rider and the second driver's status becomes 'lost'; expiry after
  CALL_TTL_MS; giveup re-opens; leaving the seat while riding gives 'left'; driverForget gives 'gone'.
