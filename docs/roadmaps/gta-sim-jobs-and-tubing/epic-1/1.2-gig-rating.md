## Change
- `src/jobs/rating.ts`:
  - `stepComfort(c, s, dt, p, job, storm)` (mutates c; dt > 0):
    1. If `!c.primed`: set lastSpeed = s.speed, lastYaw = s.yaw, lastVy = s.vy, primed = true; return.
    2. `accel = |s.speed - c.lastSpeed| / dt`; `yawRate = |wrap(s.yaw - c.lastYaw)| / dt` (wrap to -PI..PI);
       `vAccel = |s.vy - c.lastVy| / dt`.
    3. `sens = (p === 'nervous' || p === 'celebrity') ? 2 : p === 'hurry' ? 0.5 : 1`.
    4. Penalties (subtract from c.score): accel > 9: `(accel - 9) * 0.5 * sens * dt`. `lat = yawRate * s.speed`; lat > 8:
       `(lat - 8) * 0.4 * sens * dt`. `s.hpLoss > 0.005`: crashes++, `12 * sens`. `s.ranOver`: runOvers++, `25`.
       job !== 'pilot' and s.aboveGround > 0.8: `c.air += dt`, `8 * sens * dt`. job === 'pilot': vAccel > 6:
       `(vAccel - 6) * 0.3 * sens * dt`; s.stalled: `c.stalls += dt` (seconds stalled), `10 * sens * dt`.
       job === 'boat': `rough = s.waveSlope * s.speed`, `thr = storm ? 0.9 : 1.2`; rough > thr: `c.rough += dt`,
       `(rough - thr) * 6 * sens * dt`. A penalty where accel > 20 also does `c.jolts++`.
    5. Recovery: `c.score += 1.5 * dt`; clamp score to 0..100. Store last* from s.
  - `starsFor(comfort, timeRatio)`: base 5 if comfort >= 90, 4 if >= 75, 3 if >= 55, 2 if >= 35, else 1. If timeRatio > 1.5:
    base - 2; else if timeRatio > 1.15: base - 1 (timeRatio 0 = no clock: no change). Clamp 1..5.
  - `landingScore(dist, radius, vy)`: `acc = clamp(1 - dist / radius, 0, 1) * 60`; `soft = vy >= -1 ? 40 : vy <= -6 ? 0 :
    40 * (1 - (-vy - 1) / 5)`; round(acc + soft).
  - `cargoScore(dist)`: `round(100 * clamp(1 - dist / 60, 0, 1))`.
  - `cargoLanding(x, z, h, vx, vz)`: `t = sqrt(2 * max(0, h) / 18)`; return `{ x: x + vx * t, z: z + vz * t }`.
  - `payFor(st, perks, surge)`: g = st.gig.
    1. `base = g.basePay * perks.payMult * surge.payMult * (surge.celebrity ? JOB_TUNING.celebrityMult : 1)`.
    2. Parcels: if g.parcels includes 'fragile': `base *= 0.4 + 0.6 * st.condition`; else if g.parcels.length > 0:
       `base *= 0.8 + 0.2 * st.condition`.
    3. Scores (landing / cargo stops): if any `st.scores` entries: `avg` of them; kind 'cargo': `base *= 0.3 + 0.7 * avg / 100`;
       otherwise `base *= 0.6 + 0.4 * avg / 100`.
    4. `timeRatio = g.timeLimit > 0 ? st.t / g.timeLimit : 0`. `time = g.timeLimit > 0 ? base * clamp(1 - timeRatio, -0.5, 0.3) : 0`.
       For each stop i with `due` and `st.reachedAt[i] > due`: `time -= base * 0.05`.
    5. `stars = starsFor(st.comfort.score, timeRatio)`.
    6. `tip = base * JOB_TUNING.tipMax * ((stars - 1) / 4) * perks.tipMult * (surge.celebrity ? 2 : 1) *
       (g.personality === 'chatty' ? 1.2 : 1) * (g.personality === 'hurry' && timeRatio > 0 && timeRatio <= 0.8 ? 1.5 : 1)`.
    7. `bonus = g.kind === 'player-fare' ? JOB_TUNING.playerFareBonus : 0`.
    8. Round base, time, tip, bonus each; `total = max(0, base + time + tip + bonus)`; `xp = round(10 + stars * 6 + total / 5)`.
    9. notes: short lines for what applied, e.g. `Fare 34`, `Early +5` / `Late -8`, `Tip 9 (4 stars)`, `Rush hour x1.25`
       (when surge.rush), `Storm pay x1.4` (surge.storm), `Celebrity x2`, `Parcels 85%`, `Landing 92`, `Real gnome +25`.
- `src/jobs/gig.ts`: implement `stepGig(st, s, dt, storm)`:
  1. If st.phase !== 'running' return null. `st.t += dt`.
  2. If `!s.inVehicle`: `st.outT += dt`; if `st.outT > JOB_TUNING.outOfVehicleS` -> fail with 'You left the vehicle.';
     return null otherwise (nothing else runs this frame). Else `st.outT = 0`.
  3. stop = g.stops[st.idx]. If `stop.hardDue !== undefined && st.t > stop.hardDue` -> fail with
     `stop.hardReason ?? 'Too late.'`.
  4. Load effects while `loaded(st)` (idx > 0): before stepComfort, if `st.comfort.primed`:
     `jerk = |s.speed - st.comfort.lastSpeed| / dt`; `st.condition = max(0, st.condition - s.hpLoss * 3 - (s.ranOver ? 0.1 : 0)
     - (jerk > 14 ? 0.02 : 0))` when g.parcels.length > 0. Then `stepComfort(st.comfort, s, dt, g.personality, g.job, storm)`.
     When not loaded, still call stepComfort with a copy-free approach: just keep `st.comfort.lastSpeed/lastYaw/lastVy =`
     the sample and `primed = true` (so the first loaded frame has no fake jerk).
  5. While `s.aboveGround > 0.6`, store `st.touchdownVy = s.vy` (the last airborne vertical speed).
  6. Reaching (d = 2D distance to the stop):
     - 'gate': `d <= radius` and `(stop.minAlt ?? -Infinity) <= s.aboveGround <= (stop.maxAlt ?? Infinity)` -> reach.
     - 'cargo': `d <= radius` and `s.action` -> `land = cargoLanding(s.x, s.z, s.aboveGround, sin(yaw) * speed, cos(yaw) * speed)`;
       `st.scores[idx] = cargoScore(dist(land, stop))`; reach.
     - 'pickup' / 'drop' / 'land': `inside = d <= radius && s.speed < maxSpeed && (action !== 'land' || s.aboveGround <= 0.6)
       && (!stop.needsPlayer || s.playerAboard)`. inside: `dwellT += dt`, reach when `dwellT >= stop.dwell`; else dwellT = 0.
       On reaching a 'land' stop: `st.scores[idx] = landingScore(d, stop.radius, st.touchdownVy)`.
  7. Reach: `st.reachedAt.push(st.t)`, idx++, dwellT = 0. If idx === stops.length: phase 'done', return `{ t: 'done' }`;
     else return `{ t: 'reached', stop: idx - 1 }`.
  8. Fail: phase 'failed', failReason set, return `{ t: 'failed', reason }`.
- New `src/jobs/gig.test.ts` and `src/jobs/rating.test.ts`: build gigs by hand (a taxi fare of 2 stops, a 3-drop courier
  round, a pilot gig with a gate, a cargo stop and a land stop) and feed Samples. Cover: dwell needs the speed limit and
  resets when leaving; hardDue fails with its reason; out of vehicle 20 s fails; gate altitude band; cargo needs action;
