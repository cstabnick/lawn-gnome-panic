## Goal
Tubing's physics (a tube on a rope behind a moving boat: spring-damper rope, lean swing, wave launches and hops,
fall-off risk, scoring) and the Loch Moss buoy-run course work deterministically and are tested.

## Change
- `src/tubing/tow.ts`. Conventions: yaw 0 faces +z; forward `f = (sin yaw, cos yaw)`; the boat's LEFT is
  `l = (cos yaw, -sin yaw)`.
  - `hookPoint(b, slot)`: `s = TOW.slots[slot]` (clamp slot to 0..2); `{ x: b.x - f.x * b.radius + l.x * s.side,
    z: b.z - f.z * b.radius + l.z * s.side }`.
  - `newTube(b, slot, sea)`: at `hook - f * rope`, `y = sea.surface(x, z) + TOW.floatY`, all velocities 0, yaw = b.yaw,
    lean 0, air 0, risk 0, fallen false, hopT 0.
  - `stepTube(t, b, inp, sea, dt)` (mutates t; ev starts null):
    1. `t.lean += clamp((t.fallen ? 0 : clamp(inp.lean, -1, 1)) - t.lean, -TOW.leanRate * dt, TOW.leanRate * dt)`.
    2. `h = hookPoint(b, t.slot)`; `dx = h.x - t.x`, `dz = h.z - t.z`, `d = hypot`; rope unit `u = d > 1e-6 ? (dx/d, dz/d) : f`.
       `rope = TOW.slots[t.slot].rope`. Across-rope unit to the rider's right `p = (-u.z, u.x)`.
    3. `onWater = t.y <= sea.surface(t.x, t.z) + TOW.floatY + 0.02`.
    4. If `d > rope`: boat velocity `bv = f * b.speed`; `vrel = (bv - v) . u`; `a = TOW.k * (d - rope) + TOW.c * vrel`;
       `v += u * a * dt`; if `!t.fallen`: `v += p * TOW.leanForce * t.lean * dt`.
    5. If onWater: `sea.slope(t.x, t.z, s)`; `rise = s.x * vx + s.z * vz`; if `rise > 0`: `vy = max(vy, rise * TOW.launch)`.
       If `inp.hop && !t.fallen && t.hopT <= 0`: `vy = TOW.hopV`, `hopT = TOW.hopCooldown`.
    6. Drag: `k = exp(-TOW.drag * dt * (onWater ? 1 : 0.15))`; `vx *= k; vz *= k`.
    7. `vy -= TOW.gravity * dt`; `x += vx * dt; y += vy * dt; z += vz * dt`.
    8. `floor = sea.surface(x, z) + TOW.floatY`. If `y <= floor`: if `t.air >= 0.25`: ev = `{ t: 'landed', air: t.air }`,
       and if `t.air >= 0.5 && |t.lean| > 0.8 && !t.fallen`: `risk += TOW.hardLanding`. Then `y = floor`, `vy = 0`, `air = 0`.
       Else `air += dt`.
    9. `yaw = atan2(dx, dz)`.
    10. Risk: `side = |v . p|`, `sp = hypot(vx, vz)`, `add = 0`; if `side > TOW.sideFast && |lean| > 0.6`: `add += (side -
        TOW.sideFast) * TOW.sideRisk * dt`; if `sp > TOW.tooFast`: `add += (sp - TOW.tooFast) * TOW.fastRisk * dt`.
        If add > 0: `risk += add` else `risk = max(0, risk - TOW.riskDrain * dt)`. If `!fallen && risk >= 1`: `fallen = true`,
        `risk = 0`, ev = `{ t: 'fell', vx, vy: vy + TOW.throwUp, vz }` (fell wins over landed).
    11. `hopT = max(0, hopT - dt)`. Return ev.
  - `scoreStep(sc, t, ev, dt)`: if `!t.fallen`: `dist += hypot(vx, vz) * dt`, `topSpeed = max(topSpeed, that speed)`.
    ev landed: `air += ev.air`; `ev.air >= TOW.bigAirS` -> bigAirs++. ev fell: falls++.
    `points = round(dist + air * TOW.airPoints + bigAirs * TOW.bigAirPoints)`.
- `src/tubing/course.ts`:
  - `BUOY_GATES`: 6 gates forming a loop on open Loch Moss around (-700, -665), roughly 40-55 m from that centre, each
    `width` 12, yaw = the direction of travel round the loop (anticlockwise seen from above, i.e. gate i's yaw points
    towards gate i+1). Test-driven: both buoys of every gate must have `waterAt` with `depth >= 1.5`, and consecutive
    gates must be 25..90 m apart; move gates until it passes, and write the final numbers.
  - `buoysOf(g)`: left `l = (cos yaw, -sin yaw)`; `[centre + l * width/2, centre - l * width/2]`.
  - `stepRun(r, ax, az, bx, bz, dt)`: if `r.finished` return null. `r.sinceGate += dt`; if `r.next > 0`: `r.t += dt`.
    If `r.next > 0 && r.sinceGate > RUN_TIMEOUT_S`: reset to `newRun()` fields, return 'reset'. Gate g =
    BUOY_GATES[r.next]: if the segment a->b properly crosses the segment between g's two buoys AND
    `(bx - ax) * sin(g.yaw) + (bz - az) * cos(g.yaw) > 0`: if `r.next === 0` `r.t = 0`; `r.next++`, `r.sinceGate = 0`;
    if `r.next === BUOY_GATES.length`: `finished = true`, `time = r.t`, return 'finish'; else return 'gate'. Else null.
- New `src/tubing/tow.test.ts` with a flat sea (`surface = () => 0`, slope 0) and a sloped one: a boat at 12 m/s straight
  ahead pulls a tube from rest to within 2 m/s of the boat speed in 10 s, staying 0.5..2 m beyond rope length behind
  the hook; lean +1 swings it to the boat's right of the wake (positive dot with the boat's right `(-cos yaw, sin yaw)`);
  a hop on the water gives air and a 'landed' event; 25 m/s boat with hard lean eventually gives 'fell'; identical
  inputs twice give identical states (determinism); scoreStep accumulates distance and points.
- New `src/tubing/course.test.ts`: depth and spacing checks above; driving a straight line through gate 0 then gate 1
  gives 'gate' twice; crossing gate 0 backwards gives null; finishing all 6 gives 'finish' with a time; RUN_TIMEOUT_S
  idle after gate 1 gives 'reset'.
