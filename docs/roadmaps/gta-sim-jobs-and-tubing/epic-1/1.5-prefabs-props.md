## Goal
The sim jobs' world props exist in the shared prefab library (`@lawn/prefabs`): the tow tube (a vehicle body), three
roof signs, six parcels, four depot kiosks, the tube rack, a course buoy and a cargo crate.

## Read first
- `docs/roadmaps/prefab-library/_common.md`: the modelling rules, data rules and the examine voice. (Ignore its
  "Environment" section: the working directory is the one in `_env.md`.)
- `packages/prefabs/src/types.ts`: PrefabDef, Part, shapes, Category, Use (the contract; match it exactly).
- `packages/prefabs/src/palette.ts`: colour names for `c`.
- `packages/prefabs/src/catalog/gta-fish-gear.ts`: a finished GTA prop file to copy the style from (shack, sign, rack).
- `packages/prefabs/src/catalog/golf-cart.ts`: a vehicle body prefab (`seat`, `footprint`).

## Contract
The ids above, exactly (other code builds them with `buildPrefab(id)` and the 'tow-tube' vehicle spec uses `prefab:
'tow-tube'` with seat `[0, 0.32, 0]`). The anim row 'carry-parcel' holds `parcel-box` in the hand: it must have
`uses` including 'hold' and a `grip`.
