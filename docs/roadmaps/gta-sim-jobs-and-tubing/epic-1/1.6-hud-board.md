## Goal
Two DOM modules for the sim jobs: the on-duty HUD widget with its 44 px job-action button (`src/jobs/hud.ts`), and the
phone's Jobs app panel, the job board (`src/jobs/board.ts`). Both work on a phone (portrait 390x844 and landscape)
and with keyboard and gamepad.

## Read first
- `games/gnome-theft-auto/src/jobs/hud.ts` and `src/jobs/board.ts`: the stubs to fill (their interfaces are the contract).
- `games/gnome-theft-auto/src/phone/phone.ts`: the phone panel's look (CSS string injected once in a `<style>`, rows
  of 52 px buttons, safe-area insets, `pointer-events:auto`, `touch-action:manipulation`, gamepad polling with
  `firstPad()` from '@lawn/gamepad', `isTyping(e)` from '../keys'). Copy that style and the colours.
- `games/gnome-theft-auto/src/keys.ts`: `KEYS.jobAction` ('KeyI') and `KEYS.close` ('Escape'); read keys from there,
  never hard-code a code string (keys.test.ts checks).
- `games/gnome-theft-auto/src/jobs/defs.ts`: `JOBS` (title, icon, color per job), `JOB_PAD_BUTTON` (11, right stick press).
- `games/gnome-theft-auto/src/jobs/cabCalls.ts`: `RiderPhase` ('idle' | 'calling' | 'assigned' | 'riding').

## Change
- `src/jobs/hud.ts` `createJobHud(ui)`:
  - One container `#gta-job-hud` appended to `ui`, `position:fixed`, top-centre: `top: calc(env(safe-area-inset-top) +
    8px)`, `left:50%`, `transform:translateX(-50%)`, width `min(340px, calc(100vw - 200px))` (min 220px), dark translucent
    panel (`rgba(20,22,26,.8)`), 12 px radius, white system-ui text, border-left 4 px in `JOBS[view.job].color`.
    Hidden (`display:none`) when `set(null)`. `body.gta-in-scene #gta-job-hud{display:none!important}` (cutscenes).
  - Rows: title (bold 14 px) + tag pill (when `tag`), up to 3 lines (12 px), a bottom row with meter (left), timer
    `m:ss` (centre; red and prefixed `+` when negative, i.e. late) and stars (right: '★' x round(stars) + '☆' for the rest).
  - The action button `#gta-job-action`: 44 px tall, min 120 px wide, rounded, under the panel, shown only when
    `view.action` is not null, text = action label. Click -> the onAction callbacks. `pointerdown` stops propagation.
  - The I key (`KEYS.jobAction`, ignore when `isTyping(e)`) and the gamepad button `JOB_PAD_BUTTON` (edge-detected:
    poll `firstPad()?.buttons[JOB_PAD_BUTTON]?.pressed` inside `set()`, which runs every frame) fire the same callbacks,
    but only while the action button is shown.
  - `set()` writes to the DOM only when a value changed (cache the last strings); no allocation-heavy work per frame.
  - `summary(title, lines)`: a centred card `#gta-job-summary` (max-width min(360px, 92vw)), title + lines + a 44 px
    "OK" button; closes on tap anywhere on it, Escape, or after 8 s.
  - `dispose()` removes everything and the listeners.
- `src/jobs/board.ts` `createJobBoard(ui, actions)`:
  - A panel `#gta-job-board` like the phone (right side under the phone button is fine: `right: calc(env(safe-area-
    inset-right) + 10px)`, `top: calc(env(safe-area-inset-top) + 60px)`, width `min(340px, calc(100vw - 24px))`,
    `max-height: 78vh`, scrolls), z-index 37, with a header "Jobs" and a 44 px close button.
  - Sections, re-rendered by `open(view)` / `refresh(view)` (rebuild the panel's innerHTML-free DOM; use
    `document.createElement` and `textContent`, never innerHTML with view strings):
    1. One card per `view.rows` entry: icon, title, employer, `Lv {level}` and an XP bar (`xpInto / xpNeed`, full at
       need 0), done and earned counts, blurb, perks (small list). Buttons (44 px): when `onDuty` -> "Go off duty"
       (actions.offDuty); else if `!licensed && licence > 0` -> `Licence {licence} 🌰` (actions.buyLicence(job)); else
       "Go on duty" (actions.duty(job)), disabled with the `blocked` text shown under it when `blocked` is not null.
    2. "Call a cab" (rider side): when `!view.online` a line "Online only: another player on taxi duty drives you.";
       else by `view.cab.phase`: idle -> a select-like list of `view.places` as 44 px buttons (tap = actions.callCab(id));
       calling -> "Waiting for a driver to {dest}..." + "Cancel" (actions.cancelCab); assigned -> "{driver} is on the way"
       + "Cancel"; riding -> "Riding with {driver} to {dest}".
    3. When `view.calls.length > 0` (I am on taxi duty): "Player calls" with one 44 px button per call (label) ->
       actions.takeCall(key).
    4. Footer: `This shift: {shiftEarned} 🌰`.
  - Escape closes. Gamepad while open (poll with requestAnimationFrame only while open): D-pad up/down (buttons 12/13)
    moves a focus ring over the enabled buttons, A (0) clicks, B (1) closes. Stop the rAF loop when closed.
  - `refresh` keeps the scroll position.
- New `src/jobs/board.test.ts` and `src/jobs/hud.test.ts` (vitest with `// @vitest-environment happy-dom` at the top if
  `happy-dom` is in the root package.json devDependencies, else `jsdom`; check which exists and use that one; if

  licence button calls buyLicence; cab idle lists places and callCab gets the id; hud hides on set(null), shows the
