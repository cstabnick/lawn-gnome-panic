## Change
- `src/jobs/career.ts`:
  - `parseSave(raw)`: never throws. null / bad JSON / `v !== 1` -> `emptySave()`. Otherwise start from emptySave() and
    copy each field only when valid: counters finite numbers >= 0 (rounded down for counts); for each JobId a record
    whose numeric fields are finite >= 0 and `licensed` boolean (missing job records stay default); `buoyBest` a finite
    number > 0, else null.
  - `serializeSave(s)`: JSON.stringify.
  - `levelOf(xp)`: the largest i with `xp >= LEVEL_XP[i]`, plus 1 (so 0 xp -> 1, 100 -> 2, 1500+ -> 6).
  - `levelProgress(xp)`: level = levelOf(xp); `into = xp - LEVEL_XP[level - 1]`; `need = level === MAX_LEVEL ? 0 :
    LEVEL_XP[level] - LEVEL_XP[level - 1]`.
  - `recordGig(s, job, kind, pay, extra)`: r = s.jobs[job]; `before = levelOf(r.xp)`; r.xp += pay.xp; r.done++;
    r.earned += pay.total; r.bestTip = max(r.bestTip, pay.tip); if pay.stars === 5 r.fiveStars++. extra.parcels adds to
    s.parcels; extra.fragileClean -> s.fragileClean++; extra.perfectLanding -> s.perfectLandings++; extra.ferryLoop ->
    s.ferryLoops++; extra.playerFare -> s.playerFares++. Return the new level when `levelOf(r.xp) > before`, else null.
    (`kind` is accepted for future counters; it does not change anything now.)
  - `recordFail(s, job)`: s.jobs[job].failed++.
  - `statsOf(s, onDuty)`: taxiFares = jobs.taxi.done; parcels = s.parcels; flights = jobs.pilot.done; boatTrips =
    jobs.boat.done; ferryLoops; playerFares; tubeSeconds; buoyBest; earned = sum of the four records' earned; levels =
    levelOf of each record's xp; onDuty.
  - `createJobsStore(storage?)`: storage defaults to `globalThis.localStorage` when available (guard every access with
    try/catch, like fishSave). Load once with parseSave(getItem(JOBS_SAVE_KEY)). `commit()` writes serializeSave and calls
    `notifySaveChanged()`.
  - `sharedJobsStore()`: a module-level cached store: the first call creates `createJobsStore()`, later calls return the
    same object (jobs/runtime.ts and tubing/runtime.ts both use it, so they never overwrite each other's writes).
  - `jobStats()` / `bindJobStats(get)`: a module-level `let bound: (() => JobStats) | null`. jobStats returns
    `bound ? bound() : statsOf(sharedJobsStore().get(), null)`.
- `src/jobs/surge.ts` `surgeFor(job, time, sea, level, roll)`:
  - rush = (time === 'Morning' || time === 'Dusk') && (job === 'taxi' || job === 'courier').
  - storm = sea === 'blustery' && (job === 'boat' || job === 'pilot').
  - celebrity = level >= 3 && roll < 0.12 && job !== 'courier'.
  - payMult = (rush ? 1.25 : 1) * (storm ? 1.4 : 1); spawnMult = rush ? 1.5 : 1.
  - label = celebrity ? 'CELEBRITY' : storm ? 'STORM PAY' : rush ? 'RUSH HOUR' : null.
- New `src/jobs/career.test.ts`: parse of null, garbage, wrong version, partial save (keeps good fields, drops bad
  ones), the saveIO fixture `{ v: 1, jobs: { taxi: { xp: 120, done: 3, failed: 0, earned: 90, bestTip: 9, fiveStars: 1,
  licensed: true } }, parcels: 0, tubeSeconds: 12 }` parses with taxi level 2; levelOf boundaries; levelProgress at the
  top; recordGig levels up and returns the level; store round-trip with a Map-backed fake storage.
- New `src/jobs/surge.test.ts`: the rules above.
