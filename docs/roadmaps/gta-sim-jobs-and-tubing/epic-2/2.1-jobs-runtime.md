Epic: 2 (runtimes)
Depends on: Epic 1 (all jobs pure modules, hud, board, visuals implemented). Issue 2.2 (cabSync/paxSync) runs in
parallel: code against their stub interfaces, which do not change.

(Read `docs/roadmaps/gta-sim-jobs-and-tubing/_env.md` first: environment and rules for every issue.)

## Goal
`src/jobs/runtime.ts` `installJobs(deps)` makes the four sim jobs playable: go on duty from the phone's Jobs app or a
depot, gigs come in, waiting fares hail at the kerb, passengers sit in the car, parcels ride along, the HUD shows the
meter, timer, stars and next stop, the GPS points the way, pay goes through the economy, levels and achievements
count, and real players can call a cab. Off duty it costs nearly nothing per frame.

## Change
Only `src/jobs/runtime.ts` (plus `src/jobs/runtime.test.ts` for the pure helpers you export). Structure:
1. Setup: `store = sharedJobsStore()`; `bindJobStats(() => statsOf(store.get(), duty))`. `visuals = createJobVisuals(deps.scene)`;
   `const built = visuals.buildDepots(deps.world)`; push `built.boxes` into `deps.world.boxes`; `home[job]` = the spot of
   that job (or null). `hud = createJobHud(deps.ui)`; `hud.onAction(onAction)`. `board = createJobBoard(deps.ui, actions)`.
   `cab = deps.hub.register(SYS.cab, (link) => createCabSync(link, deps.net)) as CabSync`; `pax =
   deps.hub.register(SYS.pax, (link) => createPaxSync(link, deps.net, visuals)) as PaxSync`.
   `deps.phone.addApp({ id: 'jobs', label: 'Jobs', icon: '💼', detail: () => duty ? 'On duty: ' + JOBS[duty].title :
   'Taxi, courier, pilot, boat', run: openBoard })`. Rider notes (`cab.onRider`) become toasts: assigned -> `${name} is
   on the way. Ask to ride (E) when they pull up.`; riding -> `Riding with ${name}.`; paid -> `Arrived. Kerbstone Cabs
   covered the fare (${stars}★).`; reopened -> 'Your driver gave up. Waiting for another cab...'; expired -> 'No cab
   came. Try again later.'; left -> 'You got out early.' (name = deps.net.nameOf(driver) ?? 'Your driver').
2. Export pure helpers (and test them): `vehicleOk(job, spec, kind): boolean` (taxi: !flies && !boat &&
   passengerCount(spec) >= 1; courier: !flies && !boat; pilot: flies; boat: boat && kind !== 'tow-tube') and
   `needText(job)` ('Get in a car with a spare seat.', 'Get in any car, cart or bike.', 'Get in an aircraft.', 'Get in
   a boat.'); `freeSeats(capacity, taken: number[]): number[]` (seats 1..capacity not in taken, highest first);
   `kindsFor(job, perks, vehicle)` (perks.kinds filtered: pilot all three; boat water-taxi always, ferry only near the
   loop is decided by gen returning null; taxi: 'fare' only, player fares come from calls).
3. Duty: `goOnDuty(job)`: deps.blocked() -> that text; already on that duty -> 'Already on duty.'; licence: if
   `!rec.licensed` and `JOBS[job].licence > 0` -> `Buy the licence first (${licence} 🌰) on the Jobs app.`; if licence is
   0 set licensed and commit. The player must drive (`player.vehicle`, `vehicle.driver === 'player'`, `player.seat ===
   0`) a vehicle with vehicleOk, else needText. Then (going off any other duty first) set duty, dutyVehicle,
   `visuals.setSign(v, job)`, `nextGigT = 3`, reset shift stats, toast `${JOBS[job].giver}: "You're on, ${title}."`.
   `goOffDuty()`: fail any running gig (recordFail, and for a player fare `cab.giveUp()`), clear the vehicle (visuals.clearVehicle,
   `pax.setMine(null, null)`, hide waiting fares), show `hud.summary('Shift over', lines)` (gigs done, failed, earned,
   best tip, average stars) when anything happened, duty = null, `hud.set(null)`.
   Auto: while on duty with no gig, if the player drives another vehicleOk vehicle, move the sign to it; if out of
   any duty vehicle for 30 s with no gig, or the duty vehicle is exploded or sunk -> goOffDuty with a toast.
4. `update(dt)`: always `cab.tick(px, pz)` (px/pz = vehicle or player position). If `!duty`: `visuals.update(dt, px, pz)`
   and return. Else build one reusable Sample object (no per-frame allocation) from dutyVehicle: speed = |v.speed|,
   aboveGround = boats: `v.y - (waterAt(v.x, v.z)?.surface ?? v.y)`, else `aboveGround(v.x, v.y, v.z)`; hpLoss =
   max(0, lastHp - v.hp); ranOver = the flag from onRunOver (cleared after use); waveSlope (boats only) =
   hypot of `waveSlope(v.x, v.z, waveTime(), tmp)`; stalled = `!!v.spec.fixedWing && aboveGround > 2 && |v.speed| <
   (v.spec.stallSpeed ?? 0)`; action = the consumed action flag; inVehicle = `player.vehicle === v && v.driver ===
   'player' && player.seat === 0`; playerAboard = gig is a player fare and `deps.net.riders()` has its `playerFare.from`.
   - No gig: `nextGigT -= dt * perks.spawnMult * surgeNow.spawnMult`; at <= 0 call `offerGig()`: GenCtx `{ rng: Math.random,
     from, level, perks, surge, roads: ground road nodes (deps.world.roads.nodes without `deck`, computed once),
     vehicle: { kind, seats: passengerCount(spec), mass, flies, fixedWing: !!spec.fixedWing, boat: !!spec.boat },
     home: home[duty] }`; surge = `surgeFor(duty, deps.timeLabel(), seaState(), level, Math.random())` (kept for the gig);
     pick a kind from kindsFor at random and call the matching make*; null -> nextGigT = 5. Start: `gig = startGig(g)`,
     toast `New job: ${g.title}` (+ ` — ${surge.label}` when set); taxi fare: `visuals.showWaiting('fare', stop0.x,
     stop0.z, yaw facing the car, g.seed, 'hail-cab')`; boat water taxi / ferry: a waiting gnome is not needed.
   - Gig: `ev = stepGig(gig, sample, dt, surge.storm)`.
     reached stop 0 (or the first drop of a ferry): hide 'fare'; seat NPCs: `pairs = freeSeats(passengerCount(spec),
     deps.net.riders().map(r => r.seat)).slice(0, g.passengers).map((s, i) => [s, g.seed + i])`;
     `visuals.setPassengers(v, pairs, mood)` (mood: nervous personality -> 'nervous', boat with rough water -> 'seasick'
     when comfort < 60, else 'calm'); `visuals.setParcels(v, g.parcels)`; `pax.setMine({ parcels: g.parcels.length,
     seats: pairs }, v)`; a CHATTER[personality].board line: toast `${client}: "${line}"` and `speakAt(line, g.seed, x, z)`.
     reached a courier drop: drop the first parcel from the shown list (setParcels / pax.setMine again), toast
     `Delivered to ${stop.name}.`, `deps.play('door')`. Ferry stops: replace up to `stop.board` passengers (new seeds).
     Gates: `deps.play('stunt')` and toast `Gate ${n}`.
     done: `pay = payFor(gig, perks, surge)`; `deps.economy.earn(pay.total, JOBS[duty].employer)`; toast
     `+${pay.total} 🌰  ${'★'.repeat(pay.stars)}  ${pay.notes.slice(0, 3).join(' · ')}`; a CHATTER good line (stars >= 4)
     or bad line (<= 2); `level = recordGig(save, duty, g.kind, pay, extra)` with extra: courier parcels count and
     fragileClean (fragile present and condition >= 0.99), pilot perfectLanding (any land score >= 95 and passengers > 0),
     ferryLoop (kind 'ferry'), playerFare; `store.commit()`; achievements (step 6); a player fare: `cab.drop(pay.total,
     pay.stars)`; level up: `deps.hud.banner(`${JOBS[duty].title} level ${level}`)`; clear passengers/parcels/pax; shift
     stats; `nextGigT = JOB_TUNING.nextGigS`.
     failed: toast the reason; recordFail + commit; player fare -> cab.giveUp(); clear as above; nextGigT.
   - Chatter: while loaded, every 20-35 s (chatty: 10-18 s) a CHATTER ride line (toast + speakAt).
   - Taxi duty: if a player-fare gig is running and `cab.status(myId)` is 'lost' or 'gone' -> fail it with 'The fare
     cancelled.'.
   - HUD every frame: `hud.set({ job, title: gig ? gig.title + (personality !== 'plain' ? ' (' + personality + ')' : '')
     : JOBS[duty].title + ' - waiting for work', lines, meter, timer, stars: gig && loaded ? comfort.score / 20 : null, tag:
     surge.label, action })`. lines: next stop name and distance; parcels `Parcels: n (fragile 92%)`; for taxi duty
     `Player calls: n (I to accept)` when `cab.open(...)` is not empty; for a player fare `Pull up by ${name}: they ride
     with E`. timer: during a taxi pickup the patience left (`hardDue - t`), else timeLeft(gig). meter: `🌰 ${estimate}`
     (`round(g.basePay * perks.payMult * surge.payMult)`). action: 'Drop cargo' when the current stop is 'cargo' and inside
     its radius; 'Accept call' when on taxi duty, no gig and open calls; 'Next job' when no gig; else null.
   - `visuals.update(dt, px, pz)`.
5. `onAction()`: cargo -> set the action flag; 'Accept call' -> takeCall(); 'Next job' -> nextGigT = 0.
   `takeCall()` / board takeCall(key): taxi duty and no gig, else a reason; `cab.take(key)`; then
   `makePlayerFare(ctx, { key, owner, id, name, x, z, dest })` from the SeenCall and start it (passengers 0).
   `callCab(dest)`: on duty -> 'Go off duty first.'; in a vehicle -> 'Get out first.'; `cab.call(dest, getMyGnome()?.name
   ?? 'A gnome', px, pz)` (getMyGnome from '@lawn/gnome'); toast `Cab called to ${place.name}. A driver on Kerbstone duty
   will pick you up.`.
6. Achievements (deps.increment / deps.unlock with JOB_ACHIEVEMENTS): taxi done -> increment(cabbie); stars 5 ->
   unlock(fiveStar); player fare -> unlock(realFare); courier -> increment(courier, parcels); fragileClean ->
   unlock(notAScratch); pilot -> increment(pilot); perfectLanding -> unlock(butter); ferry loop -> unlock(ferry); any job
   level >= 5 -> unlock(career).
7. `waypoint()`: running gig -> current stop `{ x, z, color: JOBS[duty].color, label: stop.name, direct: duty ===
   'pilot' || duty === 'boat' }`; else null. `blips()`: current stop (kind 'objective', label), the next one (plain pin,
   job colour), open player calls on taxi duty (`#ffd23f`, label `Cab call: ${name}`), and each depot (job colour, label
   `${icon} ${depot name}`). Reuse arrays where easy.
8. `prompt(x, z)`: within 3.5 m of a depot spot -> `Talk to ${giver} (${title})`; `interact` -> open the board, true.
9. Board: `openBoard()` builds a BoardView (rows from JOBS + save + levelProgress + perksFor(...).lines, `blocked` = why
   goOnDuty would fail now or null, cab phase/driver/dest, places = LAND_PLACES (id, name), calls on taxi duty, online =
   deps.net.online(), shiftEarned) and opens it; refresh every 0.5 s while open (from update). Actions call the functions
   above and toast any reason; buyLicence: `deps.economy.spend(licence)` -> licensed + commit + toast, else 'Not enough Acorns.'.
10. `onRunOver()`: set the flag. `stats()`: statsOf(store.get(), duty). `onDuty()`, `goOffDuty()`, `forceGig(kind?)`
    (on duty and no gig, else a reason; offerGig with that kind; null or the reason it failed), `addXp(job, xp)` (add,
    commit, career check), `debug()` (JobsDebug fields: `fares` = gigs completed since load, all jobs; `gig.next` = the current stop's x/z or null; `cab` = cab.rider() phase and driver; `openCalls` = cab.open(px, pz).length).
