## Goal
The two jobs hub adapters work: `src/jobs/cabSync.ts` (player cabs: a rider's call entity, drivers mirroring open
calls, take/drop/giveup commands) and `src/jobs/paxSync.ts` (NPC passengers and parcels in a job vehicle, seen by
everyone), each unit-tested with a fake link.

## Change
- `src/jobs/cabSync.ts` `createCabSync(link, net, now)`: keep a RiderCab `r = riderIdle()`, DriverCabs `d =
  driverIdle()`, a list of rider-note callbacks. `sys: SYS.cab`, `radius: 900`, `hz: 2`.
  - collect(out): `w = riderWire(r)`; if w: `{ rec, str } = encodeCab(w)`; push `{ id: w.id, x: w.x, z: w.z, rec, str }`.
  - receive(ch): added and changed: `c = decodeCab(e.rec, e.str)`; if c: `driverSee(d, e.owner, c, now())`. removed:
    `driverForget(d, e.owner, e.id)`.
  - command(from, id, c, a): `drop = c === CAB_CMD.drop ? decodeDropArgs(a) : null`; `n = riderCommand(r, from, id, c,
    drop, now())`; emit n when not null.
  - ownerGone(owner, ents): driverForget each. update(): nothing. reset(): `d = driverIdle()`; if r.phase !== 'idle':
    riderCancel(r) and emit `{ t: 'expired' }`.
  - call(dest, name, x, z): `!link.online()` -> 'Online only: no other players here.'; `!riderCall(r, name, x, z, dest,
    now())` -> 'You already have a cab coming.'; else null.
  - cancel(): riderCancel(r). rider(): r. onRider(cb): add. tick(x, z): riderMoved(r, x, z); `n = riderTick(r, now(),
    net.riding()?.host ?? null)`; emit n.
  - open(x, z): openCalls(d, x, z). take(key): `t = driverTake(d, key)`; null -> 'That call is gone.'; else
    `link.command(t.owner, t.id, CAB_CMD.take)` and null. job(): `d.job ? d.calls.get(d.job) ?? null : null`.
    status(myId): driverStatus(d, myId).
  - drop(fare, stars): `e = driverEnd(d)`; if e: `link.command(e.owner, e.id, CAB_CMD.drop, [Math.round(fare), Math.round(stars)])`.
    giveUp(): `e = driverEnd(d)`; if e: `link.command(e.owner, e.id, CAB_CMD.giveup)`.
- `src/jobs/paxSync.ts` `createPaxSync(link, net, visuals)`: `sys: SYS.pax`, `radius: 250`, `hz: 2`. Keep `mine:
  PaxWire | null`, `myVehicle: Vehicle | null`, and `shown: Map<owner, { v: Vehicle; p: PaxWire }>`.
  - setMine(p, v): store both.
  - collect(out): if mine && myVehicle: push `{ id: 1, x: myVehicle.x, z: myVehicle.z, rec: encodePax(mine) }`.
  - receive(ch): added/changed: `p = decodePax(e.rec)`, `v = net.vehicleOf(e.owner)`; if p and v: show(owner, v, p):
    if shown has a different vehicle for that owner, `visuals.clearVehicle(old)`; `visuals.setPassengers(v, p.seats,
    'calm')`; `visuals.setParcels(v, kinds)` where kinds is `min(p.parcels, 5)` entries cycling ['mail', 'fragile',
    'food']; store. removed: clear that owner's vehicle and delete.
  - update(dt): every 1 s (accumulate dt), for each shown owner: `v = net.vehicleOf(owner)`; if v !== stored v (they
    changed vehicles or got out): clear the stored one; if v, show again with the stored p.
  - ownerGone(owner): clear and delete. reset(): clear every shown vehicle; mine stays (it is mine).
- New `src/jobs/cabSync.test.ts`: two adapters A (rider, id 1) and B (driver, id 2) wired by hand: A.call(...) ->
  A.collect gives one record -> feed it to B.receive as `added` (MirrorEnt with owner 1) -> B.open lists it -> B.take
  sends a command through a fake link (record calls) -> deliver it to A.command(2, id, 1, []) -> A's onRider gets
  'assigned' -> A.collect record has takenBy 2 -> B.receive changed -> B.status(2) 'ok' -> B.drop(40, 5) -> deliver to
  A.command -> 'paid' with fare 40 stars 5. Also: call while `link.online()` is false returns the online-only message.
- New `src/jobs/paxSync.test.ts`: with a fake visuals (records calls) and fake net.vehicleOf: setMine + collect gives
  `[1, parcels, seat, seed]`; receive added calls setPassengers on the owner's vehicle; removed calls clearVehicle.
