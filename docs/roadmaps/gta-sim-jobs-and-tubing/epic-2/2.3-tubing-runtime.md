## Goal
`src/tubing/runtime.ts` `installTubing(deps)` makes tubing a real multiplayer mechanic: a boat driver puts the tow line
out; other players hop on tubes behind it (or NPC riders when alone); each rider simulates its own tube from the
driver's relayed boat pose, leans, hops the wake and wipes out; everyone sees the ropes, riders and NPC tubes; the
driver's buoy run and a shared score; a tube rack at Mossbank to rent a tube; the 🛟 Tubing phone app; achievements.

## Change
Only `src/tubing/runtime.ts` (plus `src/tubing/runtime.test.ts` for exported pure helpers). Behaviour:
1. Setup: `view = createTubingView(deps.scene)`; `view.buildBuoys()`; `sea: Sea = { surface: (x, z) => waterAt(x,
   z)?.surface ?? heightAt(x, z), slope: (x, z, out) => waveSlope(x, z, waveTime(), out) }`; `store =
   sharedJobsStore()`. Register the adapter: `deps.hub.register(SYS.tow, (link) => adapter(link))`, keep the link.
   Phone app: `{ id: 'tubing', label: 'Tubing', icon: '🛟', detail: () => towOn ? 'Tow line out' : 'Tow riders behind
   a boat, or hop on one', run }` where run = driving a boat -> setTow(!towOn) (toast the result or reason); else
   `hopOn()` (toast reason). A small HUD line `#gta-tube-hud` appended to deps.ui (top-centre under the job HUD, 13 px
   text, translucent dark pill, hidden when not tubing): rider `🛟 {points} pts · air {s} s · team {score}` plus a risk
   bar; driver `Tow: {n} riders · team {score} · gates {g}/6 · {time}`.
2. Driver state: `towOn`, `boat` (the vehicle I drive: `player.vehicle` with `spec.boat`, `kind !== 'tow-tube'`,
   `driver === 'player'`), `slots: { who: number; npc: Npc | null; points: number }[3]` (who = player id, TOW_NPC,
   TOW_EMPTY), `run = newRun()`, `gates`, `teamScore`.
   - `setTow(on)`: needs a boat (else 'Drive a boat first.'); on -> towOn, toast 'Tow line out. Riders hop on from the
     🛟 app or swim up on a tube.'; off -> remove NPCs, empty slots, towOn false. If the player leaves the boat, tow off.
   - `addNpcRider()`: towOn (else 'Put the tow line out first.'), a free slot (else 'The tow line is full.'): Npc = {
     state: newTube(boatPose, slot, sea), score: newScore(), downT: 0, seed: 500 + slot, t: 0 }.
   - Every frame while towOn: boatPose from `boat` (speed = |boat.speed|); each NPC: input lean =
     `0.8 * Math.sin(npc.t * 0.7 + slot * 2)`, hop = every 5 s (npc.t % 5 crossing); sub-step stepTube (<= 0.05 s);
     scoreStep; on 'fell': downT = TOW.npcReboard; while downT > 0 count down, then `state.fallen = false`, risk 0.
     `view.npcTube('me:' + slot, { x, y, z, yaw, lean, riderUp: !state.fallen, seed })`.
   - Course: `ev = stepRun(run, lastX, lastZ, boat.x, boat.z, dt)`: 'gate' -> gates++, toast `Buoy ${run.next}/6`,
     `deps.play('stunt')`; 'finish' -> toast `Buoy run: ${time.toFixed(1)} s`, `deps.unlock(JOB_ACHIEVEMENTS.buoyRun)`,
     store buoyBest (min), commit, then `run = newRun()`; 'reset' -> toast 'Buoy run timed out.'. `view.highlightGate(run.next)`
     while towOn, else null.
   - teamScore = sum of slot points (players report theirs; NPCs from their score) + gates * GATE_POINTS + finished runs *
     FINISH_POINTS.
   - Occupied slots (players + NPCs) === 3 -> unlock(towCaptain); store towedMax = max; commit on change.
3. Adapter (`sys: SYS.tow, radius: 300, hz: 5`):
   - collect(out): if towOn && boat: `rec = encodeTow({ on: true, score: teamScore, gates, slots })` where an NPC slot
     sends `{ who: TOW_NPC, x, z, yaw }` of its tube and a player slot `{ who: id, x: 0, z: 0, yaw: 0 }`; push `{ id: 1,
     x: boat.x, z: boat.z, rec }`.
   - receive(ch): keep `mirrors: Map<owner, TowWire>` (decodeTow; skip null); removed -> delete, and remove that owner's
     mirrored NPC tubes (`view.npcTube(owner + ':' + i, null)`).
   - command(from, id, c, a): TOW_CMD.hook: if towOn and `from` is not in a slot, put it in the first free slot
     (toast `${nameOf(from)} hooked on.`); TOW_CMD.unhook: empty `from`'s slot; TOW_CMD.points: that slot's points = a[0].
   - ownerGone(owner): delete the mirror; if I ride behind that owner, unhook locally (toast 'Your boat left.').
   - update(): nothing; reset(): clear mirrors; a rider behind a remote boat unhooks locally.
4. Rider state: `myTube: Vehicle | null` (a tow-tube in deps.vehicles that I sit on or last sat on), `ride: { host:
   number | null; slot: number; state: TubeState | null; score: TubeScore; askT: number; secT: number }`.
   - `hopOn()`: `!deps.net.online()` -> 'Online only: ask a friend with a boat, or drive one and add NPC riders.';
     player in a vehicle -> 'Get out first.'; find the nearest mirror owner with `on` whose boat (`net.vehicleOf(owner)`)
     is within TOW.hookRange of me and has a TOW_EMPTY slot (none -> 'No boat with a free tow line nearby.'). Spawn a tube
     at `hookPoint - forward * rope` of that free slot (`createVehicle(deps.scene, 'tow-tube', x, z, boatYaw)`), push it
     into deps.vehicles, `deps.seatPlayer(tube)`, set myTube, `ride.host = owner`, `ride.slot = -1`, send
     `link.command(owner, 1, TOW_CMD.hook)`. Return null.
   - `spawnTube()` (rack): spend 5 Acorns (`deps.economy.spend(5)`, else 'Not enough Acorns.'); spawn a tube on water within
     15 m of the player (try 8 directions at 6 m and 12 m, first point with `waterAt(...)?.depth > 0.6`; none -> refund
     and 'No open water here.'); push into deps.vehicles; at most 2 rented tubes: when a third is made, remove the oldest
     that nobody sits in (`removeVehicle` + splice from deps.vehicles). Toast 'Tube in the water: swim over and hop on (E).'.
   - Auto hook (every frame, cheap): if `player.vehicle?.kind === 'tow-tube' && player.vehicle.driver === 'player'` and
     `ride.host === null`: remember it as myTube; every 2 s look for a mirror boat within TOW.hookRange with a free slot ->
     ride.host = owner, slot -1, send hook.
   - Slot check each frame while `ride.host !== null`: in `mirrors.get(host)` find my id: found at i -> if ride.slot was
     -1: `ride.slot = i`, `ride.state = newTube(pose, i, sea)` then overwrite x/z/y with the tube's current position,
     toast 'Hooked on! Lean with A/D or the stick, hop with Space or the handbrake.'. Not found and slot was set ->
     unhook locally (toast 'Let go of the tow line.'). Not found for 4 s after asking -> 'That tow line is full.' and
     host null.
   - `drives(v)`: `v === myTube && ride.host !== null && ride.slot >= 0 && ride.state !== null`.
   - `stepRider(v, inp, dt)`: boat = `net.vehicleOf(host)`; none -> unhook. BoatPose: x, z, yaw from the boat, speed
     from its movement (keep last x/z; speed = forward component of (dx, dz) / dt, eased: `s += (raw - s) * min(1, dt *
     4)`), radius = boat.spec.radius. Sub-step stepTube (<= 0.05 s) with `{ lean: inp.moveX, hop: !!inp.jump ||
     inp.lift > 0 }`; scoreStep. Write the state into v: x, y, z, yaw, `v.speed = hypot(vx, vz)`; `syncVehicleMesh(v,
     dt)`; then roll the mesh `v.object.rotation.z = -state.lean * 0.35`. Too far from the hook (> TOW.snapDist) ->
     unhook 'The rope snapped!'. On 'fell': `deps.throwPlayer(v, ev.vx, ev.vy, ev.vz)`, toast 'Wipe-out! Swim back to
     the tube and hop on.', unhook (send TOW_CMD.unhook), keep myTube (it floats; app.ts bobs it). Every 1 s while
     hooked: send `TOW_CMD.points [score.points]`; add 1 to store.tubeSeconds; every 10 s `deps.increment(tubeRider, 10)`
     and commit. Unhook stores tubeBest = max(points) and commits.
   - `unhook(reason?)`: send TOW_CMD.unhook when the host is still there, host null, slot -1, state null, toast reason.
5. Ropes and mirrored NPC tubes every frame (cap with MAX_ROPES): for my own tow (towOn): from `hookPoint(boat, i)` (y =
   boat.y + 0.4) to each occupied slot's tube (NPC: its state; player: `net.vehicleOf(who)`), rope length from TOW.slots.
   For each mirror (owner): boat = `net.vehicleOf(owner)`; slot who === my id -> my tube (myTube); who >= 0 -> that
   player's vehicle; TOW_NPC -> the record's x/z (y from sea.surface) drawn with `view.npcTube(owner + ':' + i, { ...,
   riderUp: true, seed: 500 + i })`, and empty slots remove `owner + ':' + i`. `view.ropes(list)` once per frame.
   Reuse one array of RopeSeg objects (no per-frame allocation).
6. `prompt(x, z)`: within 4 m of the rack spot (-702, -548) -> 'Rent a tow tube (5 🌰)'; interact -> spawnTube, true.
   `blips()`: the rack (`#ff7a1a`, label 'Tube rack'); while towOn the next buoy gate (kind 'objective', label `Buoy
   ${run.next + 1}`).
7. `view.update(dt, camX, camZ)` each frame (camera position = player position is fine). `debug()`: TubingDebug.
   Offline and with no tow and no tube: update() does almost nothing (a couple of checks).
Export small pure helpers and test them: `freeSlot(slots: number[]): number` (first TOW_EMPTY index or -1),
`boatSpeedFrom(prevX, prevZ, x, z, yaw, dt): number` (forward component / dt).
