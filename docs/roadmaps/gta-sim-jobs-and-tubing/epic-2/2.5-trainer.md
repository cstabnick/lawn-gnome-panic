Depends on: none inside the epic (uses the `Jobs` and `Tubing` interfaces, which are fixed)

(Read `docs/roadmaps/gta-sim-jobs-and-tubing/_env.md` first: environment and rules for every issue.)

## Goal
The Save Trainer (F9) gets a "Jobs" tab and Spawn buttons, so a tester can start any job, force a gig, add XP, call or
take a player cab, put a tow line out and add NPC riders without playing up to it.

## Read first
- `games/gnome-theft-auto/src/jobs/trainer.ts`: the stub (`registerJobsTrainer(jobs, tubing)`; app.ts calls it once).
- `games/gnome-theft-auto/src/trainer/registry.ts`: `registerTrainerSection({ id, label, order, build(el, ctx) })`,
  `registerTrainerSpawnable(group, id, label, (at, ctx) => message)`.
- `games/gnome-theft-auto/src/trainer/types.ts`: TrainerSection, TrainerSpot, TrainerCtx.
- `games/gnome-theft-auto/src/trainer/ui.ts`: heading, note, grid, row, button, select helpers.
- `games/gnome-theft-auto/src/fishing/fishing.ts` lines 440-470: a finished plug-in section (uses `status()` and
  `markTrainerModified` - find where they are imported from in that file and import them the same way).
- `games/gnome-theft-auto/src/jobs/types.ts`: Jobs (onDuty, goOnDuty, goOffDuty, forceGig(kind?), addXp, callCab,
  takeCall, debug, stats), JOB_IDS, GigKind. `src/tubing/types.ts`: Tubing (setTow, addNpcRider, hopOn, spawnTube,
  debug). `src/jobs/defs.ts`: JOBS, KIND_LEVEL. `src/jobs/places.ts`: LAND_PLACES.

## Change
Only `src/jobs/trainer.ts`:
- `registerTrainerSection({ id: 'jobs', label: 'Jobs', order: 47, build(el) { ... } })`: a status line; for each job a
  row: "On duty" (jobs.goOnDuty(job): show the returned reason or 'On duty'), "+100 XP" (jobs.addXp(job, 100) and
  markTrainerModified('jobs')); a "Go off duty" button; "Force gig" with a select of that job's gig kinds from
  KIND_LEVEL (or any) -> jobs.forceGig(kind); "Call a cab to..." select of LAND_PLACES -> jobs.callCab(id); "Take player
  call" -> jobs.takeCall(); a tubing row: "Tow line out" (tubing.setTow(true)), "Tow line in" (setTow(false)), "Add NPC
  rider" (addNpcRider), "Hop on a tow" (hopOn); a "Debug" button that writes `JSON.stringify(jobs.debug())` and
  `JSON.stringify(tubing.debug())` into the status line. Every result string (or 'OK' for null) shows in the status.
- Spawnables (group 'Jobs'): 'tow-tube' "Tow tube (rental)" -> tubing.spawnTube() ?? 'Tube in the water';
  'npc-rider' "NPC tube rider" -> tubing.addNpcRider() ?? 'NPC rider hooked on'; 'gig' "A gig now" -> jobs.forceGig()
  ?? 'Gig started'.
