## Goal
`tools/gta-jobs-mp-e2e.mjs`: a scripted two-client headless check that proves (1) a player rides as a fare in another
player's taxi (call, take, board, pick up, drop, paid) and (2) a tubing rider is towed behind another player's boat and
both clients draw the rope, with no console errors.

## Read first
- `tools/gta-mp-e2e.mjs`: the existing two-client check. Copy its launcher (puppeteer-core, browser search, `open(name)`,
  `until(page, fn, arg, ms)`, `check(ok, msg)`, error collection, cleanup in `finally`), its URL
  (`?room=...&no-intro&debug&quality=low&mp=...`) and its usage header.
- The debug hooks you will call through `page.evaluate` (`window.__gta`): `net.myId`; `player` (x, z, vehicle,
  respawn(x, z, yaw)); `spawn(kind, x, z, yaw)` (creates a vehicle and pushes it in the list, returns it);
  `jobDeps.seatPlayer(v)` (sit in it at once); `jobs` (goOnDuty(job), callCab(placeId), takeCall(), debug() -> { duty,
  gig: { kind, idx, stops, phase, next: { x, z } | null } | null, cab: { phase, driver }, openCalls, fares });
  `tubing` (setTow(on), hopOn(), debug() -> { tow: { on, slots, score, gates } | null, ride: { host, slot, points,
  fallen, air } | null, ropes }). Functions return null on success or a reason string.
- `games/gnome-theft-auto/src/jobs/places.ts`: a LAND_PLACES id to send the cab to ('clay-mart').

## Change
Only the new `tools/gta-jobs-mp-e2e.mjs`. Defaults: game `http://localhost:5442/`, mp `ws://localhost:8442/ws`
(argv[2], argv[3]). Steps (each with a clear `check` line; keep going after a failure where it makes sense):
1. Open A then B (A becomes host). Wait until each sees the other (as gta-mp-e2e does).
2. Taxi: on A, `const v = __gta.spawn('golf-cart', ax + 4, az, 0); __gta.jobDeps.seatPlayer(v); return
   __gta.jobs.goOnDuty('taxi')` -> null. On B: `__gta.player.respawn(ax + 4 + 2.2, az + 0.5, 0)` (next to A's cart),
   then `__gta.jobs.callCab('clay-mart')` -> null. Until A's `jobs.debug().openCalls >= 1` (20 s). On A
   `jobs.takeCall()` -> null and `debug().gig.kind === 'player-fare'`. Until B's `debug().cab.phase === 'assigned'`.
   On B press E (`await b.page.keyboard.press('KeyE')`, retry every 1.5 s up to 6 times) until
   `__gta.player.vehicle && __gta.player.vehicle.driver === 'remote'` (B rides in A's cart). Until A's
   `debug().gig.idx >= 1` (picked up). Then on A move the cart to the drop: `const n = __gta.jobs.debug().gig.next; const
   pv = __gta.player.vehicle; pv.x = n.x; pv.z = n.z; pv.speed = 0;` (repeat a few times over 2 s so the pose relays).
   Until A's `debug().fares >= 1` (or gig null with fares counted) and B's `debug().cab.phase === 'idle'`. Checks:
   "player fare taken", "rider boarded the taxi", "picked up", "dropped and paid".
3. Tubing: on B press E once to get out (until `!__gta.player.vehicle`). On A spawn a boat on Loch Moss and drive it:
   `const bt = __gta.spawn('gravy-boat', -700, -640, Math.PI); __gta.jobDeps.seatPlayer(bt); return
   __gta.tubing.setTow(true)` -> null. On B `__gta.player.respawn(-700, -652, Math.PI)` then until `tubing.hopOn()`
   returns null (retry each second up to 10 s: the tow record needs a moment to arrive). Until B's `tubing.debug().ride.slot
   >= 0` (hooked) and A's `tubing.debug().tow.slots` includes B's id. Then hold W on A for 4 s (`keyboard.down('KeyW')`,
   wait, `keyboard.up('KeyW')`). Checks: B's tube moved more than 5 m (read `__gta.player.vehicle.x/z` before and after),
   A's `tubing.debug().ropes >= 1`, B's `tubing.debug().ropes >= 1`.
4. No console errors on either page (print the first 5 when there are any).
Print 'all passed' or the failures; exit 1 on failure. Always close both browsers.
