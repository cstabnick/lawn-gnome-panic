Epic: 2. Depends on: none.

## Environment
Read `docs/roadmaps/level-format-2/_common.md` (and the file it points to) first.

## Goal
Club Gnome's four maps (town, gnomecino, arcade, park) live in JSON level documents instead of `maps.ts`, and the game loads them. Nothing about the maps changes: `maps.golden.test.ts` and `maps.test.ts` pass unchanged.

## Read first
- `games/club-gnome/src/maps.ts` (the data, 328 lines) and `src/config.ts` (`MapDef`, `BuildingDef`, `PortalDef`, `SpotDef`, `SeatDef`, `SignDef`, `PropDef`, `Rect`, `MAP_IDS`, `MapId`, `GAME_LINKS`).
- `games/club-gnome/src/maps.golden.test.ts`, `maps.test.ts`, `walk.ts` (how maps are read), `world.ts` (how they are drawn): they must keep working unchanged.
- `games/gnomes-of-gnomomia/src/levelDocs.ts` and one of its `data/levels/*.level.json` files: the worked example of this pattern.

## Change
- `games/club-gnome/src/data/levels/<id>.level.json` (4 files). One `LevelDoc` per map: `format 'lawn-level'`, `version 1`, `game 'club-gnome'`, `id` = the map id, `name` = a readable name (Town Square, The Gnomecino, The Arcade, Links Park), `bounds { w, d }` = the map's `w`, `d`, `base` omitted, `stamps: []`, `paths: []`,
  `props` = the map's `props` (Club Gnome's `PropDef` is the same shape as `@lawn/level`'s: copy `prefab x z rot scale tint` as they are, omit absent optional fields),
  `markers` = the spawn (`{ id: 'spawn', kind: 'spawn', x, z }`), every portal (`kind 'portal'`, `r`, `data { label, to, spawnX, spawnZ }`), every spot (`kind 'spot'`, `r`, `data { label, game }`) and every seat (`kind 'seat'`, `r`, `data { label, facing, y }`), each with its own `id`, in the order they appear in the map,
  `data` = `{ indoor, ground: '#rrggbb', wallColor?: '#rrggbb', buildings: [...], blockers: [...], signs: [...], patches?: [...] }` with every colour (`color`, `roof`, sign `color`, patch `color`) as `'#rrggbb'` and everything else exactly as in the map. Keep array order everywhere.
- `games/club-gnome/src/levelDocs.ts` (new): `export const MAP_DOCS: Record<MapId, LevelDoc<MapData>>` (import the four JSON files), `export interface MapData` (the `data` shape above), `export function docToMap(doc: LevelDoc<MapData>): MapDef` (rebuilds the `MapDef`: colours back to numbers, markers back into `portals`/`spots`/`seats`/`spawn` in file order, `patches` only when present, `wallColor` only when present) and `export function mapToDoc(map: MapDef): LevelDoc<MapData>` (the inverse; the editor will use it).
- `games/club-gnome/src/maps.ts`: replace the literal with `export const MAPS: Record<MapId, MapDef> = { town: docToMap(MAP_DOCS.town), ... }` built from the documents. Keep the file's header comment (updated to say the data lives in `data/levels/`).
- `games/club-gnome/src/levelDocs.test.ts` (new): every document passes `validateLevelDoc`; `mapToDoc(MAPS[id])` deep-equals `MAP_DOCS[id]` for all 4; `MAPS` has the same ids as `MAP_IDS`; portals' `to` all name an existing map.
- `games/club-gnome/package.json` (`@lawn/level`), `tsconfig.json` (`resolveJsonModule`) as in `_common.md`.
