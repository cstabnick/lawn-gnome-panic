## Environment
Read `docs/roadmaps/level-format-2/_common.md` (and the file it points to) first. This issue is only in `packages/prefabs`.

## Goal
The prefabs that games make solid (fountains, tents, sheds, tables, machines, bushes, rocks, trees...) carry a `footprint` (`{ r, h }`: a round collider radius and height at scale 1), so the level editor can default a prop's solid radius from the prefab instead of a number typed by hand.

## Read first
- `packages/prefabs/src/types.ts`: `PrefabDef.footprint` (already added; read its comment). `packages/prefabs/src/registry.ts`: `prefabFootprint(id)` (already added). `packages/prefabs/src/catalog/*.ts` (find each id below with `grep -n "id: '<id>'" packages/prefabs/src/catalog/*.ts`), `catalog.test.ts` (existing checks that must keep passing).
- Context for the numbers: the games use these prefabs at a scale and give them a collider; the values below are those colliders divided by the scale, rounded. They are defaults for authoring, not rules the games read.
