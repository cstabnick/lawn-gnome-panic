## Environment
Read `docs/roadmaps/level-format-2/_common.md` (and the file it points to) first.

## Goal
Gnome Golf's island and its nine holes live in a JSON level document (`src/data/levels/island.level.json`) instead of constants in `config.ts`, and the game loads them. The course does not change: `course.golden.test.ts` passes unchanged.

## Read first
- `games/gnome-golf/src/config.ts`: `ISLAND` (an `as const` object), `HOLES: readonly HoleDef[]`, `HoleDef`, `Circle`. `src/course.ts` (how they are used: `heightAt`, `lieAt`, `distToPath`, per-hole boxes).
- `games/gnome-golf/src/course.golden.test.ts` + `course.golden.json`: must pass unchanged. Also `round.test.ts` and `src/minigames/` (the party slice `golf-hole`): they must keep passing.

## Change
- `games/gnome-golf/src/data/levels/island.level.json`: one `LevelDoc`: `format 'lawn-level'`, `version 1`, `game 'gnome-golf'`, `id 'island'`, `name 'Gnome Golf Island'`, `bounds { w: 2 * ISLAND.rx, d: 2 * ISLAND.rz }` (the island's bounding box in yards, centred on 0,0), `base { id: 'golf-island', version: 1, params: { rx, rz, beach, inland, roll, seaFloor } }` (the `ISLAND` numbers), `stamps: []`, `paths: []`, `props: []`,
  `markers` = for every hole `i` (1-based): `{ id: 'tee-<i>', kind: 'tee', x, z, data: { hole: i } }`, `{ id: 'pin-<i>', kind: 'pin', x, z, data: { hole: i } }` and `{ id: 'green-<i>', kind: 'green', x, z, r: green.r, data: { hole: i } }` (read from the hole; in that order, hole by hole),
  `data: { holes: [ ...HOLES exactly as they are, every field ] }`. The markers are an index of the same points for tools; the game reads the course from `data.holes`.
- `games/gnome-golf/src/levelDoc.ts` (new): imports the JSON, exports `COURSE_DOC: LevelDoc<{ holes: HoleDef[] }>`, `ISLAND_PARAMS`-style loader `export function loadIsland(doc): typeof ISLAND`-compatible object (same field names and numeric values as before) and `export function loadHoles(doc): readonly HoleDef[]`. It must not import `config.ts` at run time (type-only imports are fine) so there is no import cycle.
- `games/gnome-golf/src/config.ts`: `export const ISLAND = loadIsland(COURSE_DOC)` and `export const HOLES = loadHoles(COURSE_DOC)` with the SAME exported types as today (keep `ISLAND`'s type so `course.ts` compiles unchanged; if it was `as const`, type it explicitly as `{ readonly rx: number; ... }`). Nothing else in `config.ts` changes.
- `games/gnome-golf/src/levelDoc.test.ts` (new): the document passes `validateLevelDoc`; `HOLES.length === 9`; every hole's `tee` and `pin` and `green` match the markers of the same hole; the document round-trips through `JSON.parse(JSON.stringify(...))` unchanged.
- `package.json` / `tsconfig.json` as in `_common.md`.
