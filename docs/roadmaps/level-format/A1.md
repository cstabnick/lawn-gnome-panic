## Environment
Read `docs/roadmaps/level-format/_common.md` first and follow it.

## Goal
The game can load the world's brush edits from a JSON file: `loadWorldDeltas()` returns a `DeltaGrid`, or `null` when the file holds no edits.

## Read first
- `packages/level/src/deltas.ts`: `DeltaGrid`, `DeltaFile` (the file form), `DeltaGrid.fromJSON(file)` (throws on a chunk of the wrong size).
- `games/gnomes-of-gnomomia/src/worldDeltas.ts`: the stub you replace.
- `games/gnomes-of-gnomomia/src/terrain.ts`: calls `loadWorldDeltas()` at import time; it must never throw.

## Change
- `games/gnomes-of-gnomomia/src/data/levels/world.deltas.json` (new directory `data/levels/` may not exist yet; create it): exactly
  `{ "format": "lawn-deltas", "version": 1, "chunk": 64, "unit": 0.01, "chunks": {} }`, pretty printed with 2 spaces, trailing newline.
- `games/gnomes-of-gnomomia/src/worldDeltas.ts`: replace the stub.
  - `import file from './data/levels/world.deltas.json';` (tsconfig already has `resolveJsonModule`).
  - `export function deltasFromFile(file: DeltaFile): DeltaGrid | null`: returns `null` when `Object.keys(file.chunks).length === 0`;
    otherwise `DeltaGrid.fromJSON(file)`; if that throws, `console.error('worldDeltas: ...', err)` and return `null`.
  - `export function loadWorldDeltas(): DeltaGrid | null { return deltasFromFile(file as DeltaFile); }`
- `games/gnomes-of-gnomomia/src/worldDeltas.test.ts` (new): empty file -> `null`; a grid with two vertices set (`setUnits(10, -5, 250)` and `setUnits(70, 3, -40)`)
  -> `toJSON()` -> `deltasFromFile` gives a grid whose `getUnits` returns the same values; a file with a chunk string that decodes to the wrong length
  (e.g. `chunks: { '0,0': 'AAAA' }`) -> returns `null` and does not throw (silence `console.error` in that test with `vi.spyOn`);
  `loadWorldDeltas()` returns `null` today.

## Contract
```ts
export function deltasFromFile(file: DeltaFile): DeltaGrid | null;
export function loadWorldDeltas(): DeltaGrid | null;   // never throws
```
