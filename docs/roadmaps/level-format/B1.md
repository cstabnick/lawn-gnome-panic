## Goal
`applyBrush` in `@lawn/level` does the four terrain brushes (raise, lower, smooth, flatten) on a `DeltaGrid` and returns an undoable patch.

## Read first
- `packages/level/src/brush.ts`: the stub with the exact signature and the `BrushOp` / `BrushMode` types (keep them as they are).
- `packages/level/src/deltas.ts`: `DeltaGrid` (`getUnits`, `setUnits`, `applyPatch`), `DeltaPatch`, `PatchBuilder`. Units are centimetres (1 unit = 0.01 m).
- `packages/level/src/math.ts`: `clamp`.

## Change
- `packages/level/src/brush.ts`: implement `applyBrush(grid, op, heightAt): DeltaPatch`. It APPLIES the dab to `grid` and returns what changed.
  - The vertices touched are the integer points `(ix, iz)` with `Math.hypot(ix - op.x, iz - op.z) < op.radius` (loop `ix` from `Math.floor(op.x - op.radius)` to `Math.ceil(op.x + op.radius)`, same for `iz`).
  - Weight `w = (1 - (d / radius) ** 2) ** 2` where `d` is that distance (1 at the centre, 0 at the rim).
  - `cur = grid.getUnits(ix, iz)`; `total = heightAt(ix, iz)` (the CURRENT total height in metres, including the grid).
  - `raise`: `next = cur + Math.round(op.strength * 100 * w)`; `lower`: minus the same.
  - `smooth`: `mean` = average of `heightAt` at `(ix, iz)`, `(ix+1, iz)`, `(ix-1, iz)`, `(ix, iz+1)`, `(ix, iz-1)`; `next = cur + Math.round((mean - total) * op.strength * w * 100)`.
  - `flatten`: `target = op.target ?? heightAt(op.x, op.z)`; `next = cur + Math.round((target - total) * op.strength * w * 100)`.
  - Clamp `next` to `[-6000, 6000]` (60 m).
  - Compute every vertex's `next` from `heightAt` FIRST, then write them all (so smooth/flatten do not depend on iteration order). Only vertices whose value changed go in the patch (`ix`, `iz`, `before = cur`, `after = next`, all in units).
  - Return `{ ix: [], iz: [], before: [], after: [] }` when nothing changed. Never throw; `radius <= 0` or non-finite inputs return the empty patch.
- `packages/level/src/brush.test.ts` (new), using a flat base `heightAt = (x, z) => 0 + grid.sample(x, z)` unless the test needs another:
  raise at a vertex centre by `strength 0.2` gives `+20` units there and less at 0.5 radius and 0 outside the radius (monotone falloff);
  lower mirrors raise; `applyPatch(patch, true)` restores the grid exactly; smooth reduces a spike (set one vertex to +200 units, smooth with strength 1: it ends lower, neighbours higher or equal);
  flatten with `target 5` over a flat zero grid raises the centre toward 5 (strength 1 at the centre moves it to 500 units, clamped to 6000);
  smooth/flatten give identical results regardless of which vertex is visited first (run twice on clones; compare);
  empty patch for strength 0 and for radius 0.

## Contract (unchanged from the stub)
```ts
export type BrushMode = 'raise' | 'lower' | 'smooth' | 'flatten';
export interface BrushOp { mode: BrushMode; x: number; z: number; radius: number; strength: number; target?: number }
export function applyBrush(grid: DeltaGrid, op: BrushOp, heightAt: (x: number, z: number) => number): DeltaPatch;
```
