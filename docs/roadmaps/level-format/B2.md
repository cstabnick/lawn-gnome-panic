Epic: 2 (integration). Depends on: none.

## Environment
Read `docs/roadmaps/level-format/_common.md` first and follow it.

## Goal
`@lawn/level` can check a level document, a delta file and a walk file for shape and sense, returning readable problems instead of throwing.

## Read first
- `packages/level/src/types.ts`: `LevelDoc`, `Stamp`, `PathDef`, `PropDef`, `MarkerDef`, `GeneratorRef`.
- `packages/level/src/deltas.ts`: `DeltaFile`. `packages/level/src/walkgrid.ts`: `WalkFile`.
- `packages/level/src/validate.ts`: the stub (keep `validateLevelDoc` and `isLevelDoc` signatures).

## Change
- `packages/level/src/validate.ts`: implement.
  - `validateLevelDoc(doc: unknown): string[]`: one string per problem, each starting with the JSON path, e.g. `stamps[2].sigma: must be a number > 0`. Empty array when fine. Never throws, even for `null`, numbers, cyclic-free junk.
    Checks: object; `format === 'lawn-level'`; `version === 1`; `game` and `id` non-empty strings, `id` matches `/^[a-z0-9][a-z0-9/_-]*$/`; `name` string;
    `bounds.w`/`bounds.d` finite numbers > 0; `base` optional: `{ id: string, version: integer, seed?: number, params: object of number|string|boolean }`;
    `stamps` array: each `op` is `'flatten'` (finite `x z inner to`, finite `outer > inner >= 0`) or `'gauss'` (finite `x z amount`, finite `sigma > 0`);
    `paths` array: `id` string, `kind` one of `'road' | 'wall' | 'fence'`, `points` array of at least 2 `[x, z]` finite pairs, `width` optional finite > 0;
    `props` array: `prefab` non-empty string, finite `x z`, optional finite `rot scale solidR` (`scale > 0`, `solidR >= 0`), optional string `tint`;
    `markers` array: `id` string, `kind` string, finite `x z`, optional finite `r >= 0`, optional object `data`; ids unique inside `paths`, and inside `markers`;
    the `data` key must be present (any value is fine, including `null`; only a missing key is a problem).
  - `isLevelDoc(doc): doc is LevelDoc` unchanged in behaviour.
  - New: `validateDeltaFile(file: unknown): string[]`: `format === 'lawn-deltas'`, `version === 1`, `chunk === 64`, `unit === 0.01`, `chunks` is an object whose keys match `/^-?\d+,-?\d+$/` and whose values are base64 strings that decode to exactly 8192 bytes (use `base64ToBytes` from `./math` inside try/catch).
  - New: `validateWalkFile(file: unknown): string[]`: `format === 'lawn-walk'`, `version === 1`, `cell === 0.25`, `inputHash` string, `tiles` array of `{ id: string, minX, minZ finite, cols, rows positive integers, rle: base64 string }`, unique ids, and the RLE decodes with `decodeRle(base64ToBytes(rle), cols * rows)` without throwing (try/catch -> problem string).
- `packages/level/src/validate.test.ts` (new): a minimal valid doc returns `[]`; for each rule above one test that breaks exactly that rule and expects exactly one problem whose text contains the path; junk inputs (`null`, `42`, `'x'`, `[]`, `{}`) return problems without throwing; a delta file built with `new DeltaGrid()` + `setUnits(...)` + `toJSON()` is valid and the same file with one chunk string `'AAAA'` is not; a walk file built from `new WalkGrid()` + `bakeTile('t', {minX:0,maxX:4,minZ:0,maxZ:4}, () => false)` + `toJSON()` is valid and with `rows: 0` is not.

## Contract
```ts
export function validateLevelDoc(doc: unknown): string[];
export function isLevelDoc(doc: unknown): doc is LevelDoc;
export function validateDeltaFile(file: unknown): string[];
export function validateWalkFile(file: unknown): string[];
```
(`index.ts` already does `export * from './validate'`.)

All other files in `packages/level`. Do not make the validator check anything about `data` or about prefab ids.
