Epic: 2 (integration). Depends on: none.

## Environment
Read `docs/roadmaps/level-format/_common.md` first and follow it. Browser tool: no dev server; keep picking maths pure and tested.

## Goal
The Select tool: place, pick, drag, edit the fields of, and delete the things in a zone (regions, lakes, houses, decks, props, stamps), with undo for every change.

## Read first
- `tools/level-editor/src/context.ts`: `Tool`, `EditorContext` (`zone`, `zones`, `select`, `selection`, `events`, `editZone`, `touch`, `viewport.pick/dom/focus`, `terrain.heightAt`, `status`), `CollectionDef`, `FieldDef`, `Item`, `MutableZone`.

## Change
- `tools/level-editor/src/tools/selectMath.ts` (new, pure; no DOM, no three.js): `export function pickItem(def: MutableZone, collections: readonly CollectionDef[], x: number, z: number, minPick = 1.5): { collection: string; index: number } | null`. For every collection and every item of `items(def)` that `accepts` (all when absent), the distance `d = hypot(item.x - x, item.z - z)`; an item is a candidate when `d <= max(radius(item), minPick)`; return the candidate with the smallest `d / max(radius(item), minPick)` (ties: the later collection in the list wins). `index` is the position in `items(def)` (not in the filtered view). `null` when none.
- `tools/level-editor/src/tools/selectMath.test.ts` (new): picks the nearest; a small lake inside a big region picks the lake near its centre and the region near the region's edge; `accepts` filtering (a stamp of the other op is ignored, and the returned `index` is into the raw array); `minPick` lets a tiny item be hit; `null` far away.
- `tools/level-editor/src/tools/select.ts`: implement.
  - Panel: a row of "Add" buttons, one per collection (`COLLECTIONS` labels); at most one is armed (class `on`); a second click disarms. A line `Click the ground to place. Esc cancels.` while armed. Under it an "Items" list per collection (a `<h3>` with the label and the count, then one button per item: `<label or id or index>  (x, z)`, click selects it and `ctx.viewport.focus(item.x, item.z)`), rebuilt on `ctx.events.changed`, `selection` and `zone`. Under that the Inspector for `ctx.selection`: for each `FieldDef` of its collection a labelled input (`number` -> `<input type=number step min max>`, `text` -> text, `enum` -> `<select>`), the position (`x`, `z`, number inputs) and a Delete button. Changing a field commits on `change` (not on every keystroke) with ONE `ctx.editZone('Edit <label> <field>', zone, def => { items(def)[index][key] = value })` (numbers parsed with `Number`, ignore NaN). Delete: if `collection.deleteBlocked?.(def, index)` returns a string, show it with `ctx.status` and do nothing; otherwise `ctx.editZone('Delete <label>', ...)` splices the item, then `ctx.select(null)`.
  - `activate()`: listeners on `ctx.viewport.dom`: `pointerdown` (button 0), `pointermove`, and on `window` `pointerup`/`pointercancel`/`keydown` (`Escape` disarms and clears the selection, `Delete`/`Backspace` deletes the selection unless an input is focused).
  - Armed + click: `hit = ctx.viewport.pick(ev)`; `ctx.editZone('Add <label>', ctx.zone, def => { const list = c.items(def); list.push(c.make(hit.x, hit.z, hit.y)); })` then select it (`index = list.length - 1`, read after the edit) and disarm.
  - Not armed + click: `pickItem(ctx.zones[ctx.zone] as MutableZone, COLLECTIONS, hit.x, hit.z)`; select it (or `null` when nothing is hit). When the pick is the item that is already selected, start a DRAG: remember the item's start `x, z` and the offset between the click and the item's centre; `ctx.viewport.setLeftOrbit(false)` is already the case in this tool. On `pointermove` while dragging: set `item.x/item.z` directly on the live object (`items(def)[index]`) to `hit - offset` and call `ctx.touch(zoneRect)` where `zoneRect` is `import { zoneRect } from '../state'` of the zone def (so terrain, roads and flora follow the item live; this is a preview, no undo entry). On `pointerup`: if the item moved, put it back to its start position and then call `ctx.editZone('Move <label>', ctx.zone, def => { set x, z to the final position })` so the undo snapshot is right.
  - `deactivate()`: remove listeners, disarm, finish or cancel a drag (cancel = restore the start position and `ctx.touch`).
