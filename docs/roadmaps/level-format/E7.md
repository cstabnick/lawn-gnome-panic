## Environment
Read `docs/roadmaps/level-format/_common.md` first and follow it. The server code runs inside the Vite dev server (Node); the client code runs in the browser. You cannot start the dev server; test the pure request handler instead. `validateLevelDoc`, `validateDeltaFile` and `validateWalkFile` in `@lawn/level` are being written by another worker (the first two exist as stubs now; `validateDeltaFile`/`validateWalkFile` may not exist yet when you start). Import them from `@lawn/level` anyway; if a name is missing from the package when you type-check, wait for it by re-checking after you have done everything else, and if it is still missing say so.

## Goal
The editor can save: the dev server writes the three kinds of level file into the game's `src/data/levels/` folder safely, and the page sends them.

## Change
- `tools/level-editor/server/handler.ts` (new, pure: no `fs`, no Vite): 
  `export function handleLevelRequest(req: { method: string; route: string; body: string }, levelsDirRel: string): { status: number; json: unknown; write?: { relPath: string; text: string } }`.
  - Routes (all `POST`, body is JSON text; `GET /status` returns `{ ok: true }`): `/zone` with `{ doc }` -> `validateLevelDoc(doc)` must be empty; `doc.game` must be `'gnomes-of-gnomomia'`; `doc.id` must match `/^[a-z0-9-]+$/` (no slashes: only authored zones are saved); writes `<levelsDirRel>/<id>.level.json` with `JSON.stringify(doc, null, 2) + '\n'`. `/deltas` with `{ file }` -> `validateDeltaFile(file)` empty; writes `<levelsDirRel>/world.deltas.json` (`JSON.stringify(file, null, 2) + '\n'`). `/walk` with `{ file }` -> `validateWalkFile(file)` empty; writes `<levelsDirRel>/walk.bake.json` (`JSON.stringify(file, null, 1) + '\n'`).
  - Anything else: 404. Bad JSON, a body over 20 MB, or validation problems: 400 with `{ error: string, problems?: string[] }`. The file name is built ONLY from those fixed names and the checked id: never from any other part of the request.
  - Return `{ status: 200, json: { file: relPath }, write }` on success.
- `tools/level-editor/server/handler.test.ts` (new): a valid zone document (build a minimal one in the test) writes `<dir>/mossbottom.level.json`; an id with `../` or a slash or capitals is rejected and nothing is written; a document that fails `validateLevelDoc` gives 400 with `problems`; `/deltas` and `/walk` accept the files their classes produce (`new DeltaGrid()` with a vertex set + `toJSON()`, `new WalkGrid()` + `bakeTile` + `toJSON()`) and reject junk; unknown route 404; invalid JSON 400; oversize body 400.
- `tools/level-editor/server/api.ts`: implement `levelApi`: a Vite plugin with `configureServer(server)` mounting `server.middlewares.use('/api', ...)`, reading the request body (string, abort with 400 above 20 MB), calling `handleLevelRequest({ method, route: url without the query, body }, relative(repo, levelsDir))`, and on a `write` result `mkdirSync(dirname(abs), { recursive: true })` + `writeFileSync(resolve(repo, relPath), text)` where `abs` is checked to be inside `levelsDir` (`resolve(...).startsWith(levelsDir + sep)`), then `res.end(JSON.stringify(json))` with `content-type: application/json` and the status. Errors become 500 JSON `{ error }`.
- `tools/level-editor/src/persist.ts`: implement.
  - `async function post(route: string, body: unknown): Promise<{ file: string }>` using `fetch('/api' + route, { method: 'POST', headers: { 'content-type': 'application/json' }, body: JSON.stringify(body) })`; on a non-OK response throw `new Error(json.error + (json.problems ? ': ' + json.problems.join('; ') : ''))`.
  - `saveAll(ctx)`: for every id in `ctx.dirty.zones`: `post('/zone', { doc: worldZoneToDoc(ctx.zones[id]) })`; when `ctx.dirty.deltas`: `post('/deltas', { file: ctx.deltas.toJSON() })`. Collect the returned `file`s; after all succeed, clear `ctx.dirty.zones` and set `ctx.dirty.deltas = false`; return `{ files }`. If anything fails, throw and clear nothing for what failed (clear what succeeded). Leave `ctx.dirty.walkRects` alone (the Analyze tool re-bakes). When anything was saved and `ctx.dirty.walkRects.length > 0`, also call `ctx.status('Saved. The walkability bake is now out of date: use Analyze > Re-bake.')`.
  - `saveWalk(file)`: `post('/walk', { file })` and return `{ files: [file] }`.
