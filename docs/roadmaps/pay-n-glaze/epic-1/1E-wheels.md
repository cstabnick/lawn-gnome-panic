## Goal
New tyres and rims on a vehicle's wheel pivots, wheel size, and camber that stays correct while the wheel spins and steers.

## Change
- `packages/glaze/src/wheels.ts`:
  - Constants: `TYRE_WIDTH: Record<TyreId, number>` = `{ stock: 1, fat: 1.7, slim: 0.55, whitewall: 1, knobbly: 1.3, cart: 0.5, saucer: 1.5 }` (a multiple of the wheel's stock width); `RIM_FRACTION = 0.62` (rim diameter as a fraction of the tyre diameter).
  - `applyWheels(root, mounts, loadout)`: for every `w` in `mounts.wheels`, `group = root.getObjectByName(w.pivot)` (skip when missing). **Stock measurement:** the first time a group is seen (`group.userData.glazeStock` unset), if it has at least one child, measure it from its children (each child's `geometry.boundingBox` transformed by the child's local matrix; call `child.updateMatrix()` first): `radius = max(size.y, size.z) / 2`, `width = size.x`, and store `group.userData.glazeStock = { radius, width, y: group.position.y }`. A group with no children and no record (a damage stage removed the wheel) is skipped entirely: a wheel that was removed stays removed. **Custom wheel:** when `tyre !== 'stock' || rim !== 'stock' || wheelSize !== 1`: set every ORIGINAL child (those without `userData.glaze`) to `visible = false` (hide, never remove: going back to stock must restore them), remove any earlier child with `userData.glaze`, then add a `THREE.Group` holder (`userData.glaze = true`, `name: 'glaze-wheel'`) containing the tyre and the rim. `R = stock.radius * loadout.wheelSize`, `Wd = stock.width * TYRE_WIDTH[loadout.tyre]`. The tyre: build prefab `glaze-tyre-<id>` (`stock` has one too, a plain black tyre); if the prefab is missing, fall back to a plain `CylinderGeometry(0.5, 0.5, 1, 14)` rotated `z = PI/2` with a dark `MeshStandardMaterial` so the wheel never disappears. Build prefab `glaze-tyre-<id>` with `buildPrefab`, set `inner.position.set(0, -0.5, 0)` (so the hub is at the holder's origin), put it in a `THREE.Group` `tyreHolder` with `scale.set(Wd, 2 * R, 2 * R)`. The rim: `buildPrefab('glaze-rim-' + loadout.rim, { tint: loadout.rimColor })`, same `-0.5` offset, in a holder scaled `(Wd * 0.9, 2 * R * RIM_FRACTION, 2 * R * RIM_FRACTION)`. If the rim prefab is missing, add no rim. For a wheel on the right side (`w.side === -1`) set `holder.rotation.y = Math.PI` so the rim face points outward (-x). Set `castShadow = true` on every mesh. **Lift:** `group.position.y = stock.y + (R - stock.radius)` so the tyre bottom stays on the ground (and `= stock.y` when customised back to stock, with the original children visible again and the glaze holder removed). `lift` returned = the mean of `(R - stock.radius)` over the wheels found (0 when none). **Spinners:** for `rim === 'spinner'` push `{ object: rimHolder, rate: 6 }` (the rim holder spins about x on its own; since it is a child of the spinning wheel, a slow independent spin makes the blades keep turning). `wheels` returned = the groups by index 0..3 (`undefined` where missing).
  - Idempotent and cheap to repeat: calling twice gives identical results (it removes its own holders first and re-measures nothing: `glazeStock` is stored on the group).
  - `setWheelPose(wheel, spin, steer, camber)`: `wheel.rotation.order = 'ZYX'`, then `wheel.rotation.set(spin, steer, side * camber)` where `side = wheel.position.x < 0 ? -1 : 1` ... **work out the sign yourself and prove it in the test:** a NEGATIVE camber must lean the TOP of both wheels toward the vehicle's centre line. (Hint: rotating about +z by an angle `a` moves the point `(0, 1, 0)` to `(-sin a, cos a, 0)`; so for the +x (left) wheel a negative `a` moves the top to +x... check which way is "in" for each side and pick the sign.) All angles RADIANS.
- `packages/glaze/src/wheels.test.ts` (new): with fake geometry (do not depend on the real prefabs): build a `THREE.Group` root with a child group named `wheel-0` at `(-0.6, 0.275, -0.55)` containing one `CylinderGeometry(0.275, 0.275, 0.2)` mesh rotated `z = PI/2`, and `wheel-2` at `(0.55, 0.175, 0.6)` with a smaller one; hand-write `mounts.wheels` for them. Stock loadout -> `lift === 0`, group children unchanged and visible, `position.y` unchanged. `wheelSize: 1.4` -> `position.y` rose by `0.4 * radius`, the original child is hidden, a child with `userData.glaze` exists, `lift` is the mean (about `0.4 * 0.225`). Applying twice leaves exactly one glaze child. Back to stock restores visibility, removes the holder and `position.y`. A wheel group with no children is untouched and never gets a holder. `setWheelPose`: for a wheel at `x = +0.5` and one at `x = -0.5` with camber `-0.1`, the world position of the local point `(0, 1, 0)` ends with its x moved TOWARD 0 for both (after `wheel.updateMatrixWorld()`), with spin 0 and steer 0; and with spin 1.2 rad and camber -0.1 the wheel's axle (local x axis transformed to parent space) still equals the camber-only tilt (the spin does not change the axle direction).
