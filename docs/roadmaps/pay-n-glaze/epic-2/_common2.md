# Extra common rules for the epic-2 (Gnome Theft Auto adoption) issues

Read `docs/roadmaps/pay-n-glaze/_common.md` first; it applies. In addition:

- Epic 1 has landed: `@lawn/glaze` (`packages/glaze/src`) is implemented (paint, decals, wheels, lamps, fittings, steer, attach, grips, loadout, mounts) and the `glaze-*` prefabs exist. `packages/glaze/README.md` may not exist yet; the source files are the documentation. Public API: `import { ... } from '@lawn/glaze'` (see `packages/glaze/src/index.ts`).
- The game is `games/gnome-theft-auto` (workspace name `gnome-theft-auto`). Its vehicles are `Vehicle` objects (`src/types.ts`; the new fields `look?: Loadout` and `rig?: GlazeRig` already exist) built in `src/vehicles.ts`. Ground vehicles are the kinds in `GLAZE_KINDS` (`src/glazeStore.ts`): `push-bike`, `ride-on`, `zero-turn`, `combine`, `lowrider`, `boot-float`, `snail-coach`, `mulch-spreader`, `hoa-van`. Flyers (`plane`, `whirligig`) and boats are NOT dressed: they keep the old build path.
- Stubs that other issues fill (their exported names and shapes are final, you may call them): `glazeMounts.ts registerGlazeMounts()`, `glazeStore.ts` (`ownedLoadout`, `saveOwnedLoadout`, `clearOwnedLoadout`, `onOwnedChange`, `GLAZE_KINDS`), `glazeShop.ts createGlazeShop`, `glazeUi.ts` (widgets and the `Panel`/`PanelCtx` types), `glazePanel{Paint,Wheels,Lights,Body}.ts`, `driverHands.ts poseHands(model, vehicle, seat)`, `vehicles.ts setVehicleLook(v, look)`, `net.ts GtaNet.setLook` / `NetEvents.onPeerLook`, `remotes.ts Remotes.setLook`, `garages.ts GarageDeps.setLook/showroom`.
- Rules from AGENTS.md that apply to this game: `npm run build -w games/gnome-theft-auto` must pass at the end (the PLANNER runs it; you run `npx tsc --noEmit -p games/gnome-theft-auto` and the vitest files you touch: `npx vitest run games/gnome-theft-auto/src/<file>.test.ts`). The existing tests must keep passing: run `npx vitest run games/gnome-theft-auto/src/bump.test.ts games/gnome-theft-auto/src/handling.test.ts games/gnome-theft-auto/src/seats.test.ts games/gnome-theft-auto/src/net.test.ts` if you touched anything they cover. UI is mobile-first (44 px targets, safe-area insets, nothing hover-only). Keep tuning numbers in `config.ts` only when the issue says so.
- The GTA game has a `gta-getaway` party slice (`src/minigames/`); do not touch it. `npm test -w games/gnome-theft-auto` must still pass.
- Do not run any dev server (the planner's is on port 5198).
