# CRN knob sweep: r2

60 Latin-hypercube configs x 12 mirror matches (champion-v2 vs champion-v2, 45 s quarters, 150 ms cadence). Seeds 1..12 are shared by every config (common random numbers). Elapsed 10.8s.

## Notes

- Swing is the median over matches of (sum of |change in home-away diff| per score step) / (score count). Score-step paths only move by the points scored, so this equals points per score; it is a coarse proxy. Real GEI needs per-tick win probability (see scorecard).
- Dunk share, possession seconds and passes per possession are pooled over all matches in a config.
