# Gnome Company: Chapel of Mulch

A satirical, spooky, absurd multiplayer co-op scavenging game inspired by *Lethal Company*.

Serve **Omnipresent Gnome Jesus** from your rickety **Garden Shed** base. Invade the **Suburban Nightmare Yard**, crawl into the **Great Deku Oak**, break into the **Cursed House**, dodge **Giant Earthworms**, **Possessed Lawn Mowers**, **Acorn-Throwing Squirrels**, **Giant Spiders**, and **Evil Shadow Gnomes** — while befriending a **Creepy Rolling Pillbug** and a **Giant Goofy Fetch Dog** who never hurts you.

## Running

- Client (Vite): `npm run dev -w games/gnome-company` (http://localhost:5175)
- Multiplayer Server: `npm run dev -w games/gnome-company-server` (ws://localhost:8788/ws)
- Solo / Offline mode works directly in the browser without starting the server.
