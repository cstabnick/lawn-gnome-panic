# Gnome Souls

A semi-horror dark-fantasy Soulsborne demo set in the Sunken Spigot culvert. Wield the two-handed Kiln-Breaker Greatsword, manage stamina and i-frame dodge rolls, fight past Hollow Gnomes, and face **Slink, the Uncoiled Hose** solo or in 1–4 player `@lawn/mp` co-op.

## Run

```sh
npm run dev -w games/gnome-souls
```

URL shortcuts:
- `?autostart=solo` — skip the title screen into solo play
- `?boss=1` — spawn at the Sunken Spigot Basin facing Slink
- `?touch=1` — force mobile touch controls on desktop
- `?nohud=1` — hide HUD overlays
