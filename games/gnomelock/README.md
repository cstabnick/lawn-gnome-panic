# Gnomelock

A 2v2 Deadlock-parody 3D MOBA set in **The Bramble District**.

## Run

```sh
npm run dev -w games/gnomelock      # http://localhost:5207/
npm run sim -w games/gnomelock      # 30-match headless balance simulator
npm test -w games/gnomelock         # unit tests
npm run build -w games/gnomelock    # type-check + vite build
```

## Controls (Desktop & Mobile)

- **Move:** `WASD` (or left virtual stick on mobile)
- **Aim / Shoot:** Mouse + `LMB` (`RMB` ADS zoom, `R` reload)
- **Jump / Double Jump / Wall Jump:** `Space` (wall-jump costs 0 stamina & resets double jump)
- **Dash / Dash-Jump:** `Shift` (press `Space` mid-dash for a speed-preserving Dash-Jump)
- **Power Slide:** `Ctrl` or `C` (downhill speed boost + infinite ammo + +15% fire rate)
- **Abilities:** `Q`, `E`, `F`, `X` (or `1`, `2`, `3`, `4`)
- **Shop:** `B` (in Base or near Mid-Lane Garden Sheds)
- **Scoreboard:** `Tab`
