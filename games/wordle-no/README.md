# Wordle (the answer is no)

Literally Wordle: 6 guesses, green / yellow / grey tiles, an on-screen keyboard, a share button.
The only answer is NO. (So the board is two letters wide.)

Run: `npm run dev -w games/wordle-no`. Tests: `npm test -w games/wordle-no`.
Single-player, no player character, no online (a daily puzzle with one answer has nothing to race).
